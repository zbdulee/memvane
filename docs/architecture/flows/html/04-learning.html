04 학습 파이프라인

사용자가 setup에서 학습 방식을 고르고 프로젝트를 등록해 두면, 백그라운드 project worker(등록 프로젝트 전용 학습 실행기)가 조건을 하나씩 확인하고, 모두 확실할 때만 제한된 양을 학습합니다.

학습은 색인·검색과 분리되어 있습니다. 하나라도 불확실하면 학습하지 않고 상태만 반환합니다.

  1. 학습 방식 선택

    사용자 선택연결 미검증

    입력setup에서 학습 정책을 고릅니다: 현재 상태 유지, 로컬 자동 적용, 로컬 단계적 적용, 또는 끄기입니다.

    결과이 선택이 learning setup 파일과 어떻게 연결되는지는 확인하지 못했습니다.

  2. 설정·준비 확인

    자동즉시 판정

    처리capture·autoCycle·indexing 설정과 safe root를 봅니다. setup 단계가 activated인지도 봅니다.

    멈춤실패하면 disabled 또는 setup_in_progress를 반환합니다.

  3. 자원 확인

    자동비차단 — 기다리지 않음

    처리프로젝트 lock을 기다리지 않고 잡아 봅니다. 이어서 resource report와 local_train scope를 확인합니다.

    멈춤lock이 점유 중이면 busy, 자원이 부족하면 deferred_resource를 반환합니다.

  4. 동의·예산 확인

    자동동의는 사용자 소유

    처리synthetic local-only면 예산만 봅니다. 아니면 teacher 대기 사례, 동의, weekly quota를 봅니다.

    멈춤불확실하면 새 로컬 모델 호출로 가지 않고 busy·deferred_*·consent_required를 반환합니다.

  5. 제한 학습 실행과 기록

    자동실제 학습 QA 미실행

    처리run_training_pending이 정해진 양만 실행합니다.

    저장진행 위치는 두 head slot의 cursor에, 결과 상태는 project-last-status.json에 남습니다. 결과가 applied·already_applied일 때만 checkpoint 선택 pointer가 바뀐 것으로 표시됩니다.

  6. 다음 실행·중단 후 재개

    자동

    다음중단 후 다시 들어오면 cursor에서 이어갑니다. 이미 완전히 커밋된 cursor는 모델을 다시 돌리지 않고 recover_completed로 완료를 확인합니다.

구현됨 ≠ 검증됨. 위 단계는 구현된 코드 경로입니다. 실제 학습은 QA에서 실행하지 않았습니다. 학습이 통과했다거나, 결과가 recall에 반영된다거나, 운영에 적용되었다고 볼 수 없습니다.

혼동 주의. 이 흐름은 원문 파일, 생성 위키 카드, QMD, Laya 위키 전용 색인의 저장·검색 경로가 아닙니다. 선택된 Laya 설치의 상주 임베딩 모델 소유 프로세스도 학습 worker가 아닙니다. 학습은 별도의 학습 상태 root와 checkpoint만 다룹니다.

자세히 보기

멈춤 상태 한눈에 보기
상태언제학습 여부
disabled / setup_in_progress설정 플래그·safe root 실패, setup 미활성안 함
busyproject-worker.lock 점유 중 등안 함
deferred_resource 등 deferred_*resource report 부족·보류, 예산 미준비안 함
consent_requiredteacher 동의 또는 quota 불확실안 함

각 상태는 즉시 반환됩니다. 다음 시도 시점은 이 페이지 범위 밖입니다.

중단·복구가 안전한 이유
  • cursor는 두 head slot과 group-plan.json·cursor.json을 씁니다. 쓰기가 중간에 끊겨도 이미 커밋된 head를 덮어쓰지 않습니다.
  • 완료 영수증은 request·artifact hash에 고정됩니다. publish 작업이 아닙니다.
  • 완전히 커밋된 cursor만 모델 실행 없이 완료로 처리합니다.
저장 위치
  • 학습 상태 root: cursor, plan(group-plan.json), head (사유 기록 포함)
  • project-last-status.json: 마지막 실행 결과 상태
  • project-learning-setup.json: setup phase. activated가 아니면 준비 안 됨
  • checkpoint 선택 pointer: applied일 때 갱신 (코드 발췌 범위 밖, 아키텍처 지도 근거)

QA 증거와 미검증 항목
  • QA 기록: docs/release-agent-qa.md. 실제 학습은 실행하지 않았습니다.
  • 학습 결과의 recall 반영은 검증하지 않았습니다.
  • checkpoint 선택 pointer(live_select)는 발췌 범위 밖입니다.
  • learning profile action ↔ project-learning-setup.json 연결은 확인하지 못했습니다.

이 프로젝트의 용어

project worker
명시 등록된 프로젝트만 제한된 양으로 학습하는 비동기 실행기. core/context_learning/project_worker.py
learning choice
setup에서 고르는 학습 방식(preserve·local-auto-apply·local-staged·off). --learning-choice, core/setup_entry.py
learning setup
프로젝트 학습 준비 상태. phase가 activated여야 진행. project-learning-setup.json
safe root
학습이 허용된 안전한 프로젝트 경로 조건. project_worker.py:15-24
resource report
학습 전에 확인하는 자원 상태 보고. context_learning.resource_coordination
local_train scope
로컬 학습이 허용되는 자원 범위. project_worker.py:27-38
synthetic local-only
로컬 합성 데이터만 쓰는 모드. teacher 대신 예산만 확인.
teacher
학습 사례를 제공하는 쪽. 사용자 동의가 필요. 대기 사례를 확인.
weekly quota
teacher 경로의 주간 사용 한도.
cursor
학습 진행 위치 기록. cursor.json, UpdateCursor, training_cursor.py
두 head slot
cursor를 번갈아 쓰는 두 칸. 중단돼도 커밋된 head 보존.
recover_completed
커밋된 cursor를 모델 실행 없이 완료로 확인하는 재진입 처리.
applied / already_applied
학습 결과 적용 상태. 이때만 activeCheckpointChanged가 참.
checkpoint 선택 pointer
사용할 checkpoint를 가리키는 값. live_select (발췌 범위 밖)
disabled
설정 플래그가 꺼져 학습 안 함.
setup_in_progress
setup이 아직 activated가 아님.
busy
project-worker.lock 점유 등으로 지금 실행 불가.
deferred_* / deferred_resource
자원·예산 사유로 보류.
consent_required
teacher 동의나 quota가 불확실해 진행 안 함.
