# 기능별 아키텍처 흐름도

바로 읽을 수 있는 Claude 작성 HTML판은 [기능별 HTML 목차](html/README.html)에서 시작하세요. 다섯 페이지는 각각 독립된 파일이며, 저장소에서 내려받아 브라우저로 열면 단계 설명과 접을 수 있는 용어·복구 설명이 표시됩니다. GitHub의 파일 화면은 HTML 실행 미리보기가 아닙니다.

HTML 원문은 Claude Opus 5.5가 기존 공개 흐름도 여섯 파일을 입력으로 각각 작성했습니다. Codex는 코드와 대조해 샌드박스 가드 문구 등 몇 군데를 바로잡고, 상대 링크·용어집·로컬 데스크톱 렌더를 확인했습니다. 작성 가드 기록은 목차 `0cc129dbadf943028e7022fcf9fadf7c`, 기능 순서대로 `f7761d53125543ec93921a3d11b94922`, `4f7f9e22d9ca455da11283be831ad546`, `04433784a7954dbc8dca4b3ed4e48f25`, `43f4fa1ea3e646dfa5751afedec46997`, `d855d9e8e83948d99a534e6a0c9bde8d`입니다. 이 작성은 qmdqa 실제 호스트 QA의 모델 호출 원장과 별개입니다.

아래 다섯 흐름도는 2026-10-25 기준 구현 코드와 QA 계약을 읽고 **Claude Opus 5.5가 작성한** Markdown/Mermaid 문서입니다. Codex는 코드와 대조해 호스트 지원 범위와 링크를 검토했습니다. 다이어그램은 설계·구현 이해를 돕는 자료이며, 아직 끝나지 않은 실제 호스트 QA의 통과 증명은 아닙니다.

각 문서에는 입력과 출력, 저장소, 동기·비동기 작업, 권한 경계와 실패·복구 분기가 표시돼 있습니다. 전체 구현 설명은 [상위 아키텍처](../../architecture.md), 현재 검증 상태는 [QA 현황](../../release-agent-qa-status.md), 행별 기준은 [QA 계약](../../release-agent-qa.md)을 보세요.

원문 파일은 위키 생성과 출처·최신성 확인의 입력입니다. Laya의 독립 문서 색인·검색에는 위키만 들어가며, 위키 카드 안의 정리된 발췌와 원문 위치 링크는 그대로 유지합니다. 호스트 에이전트가 링크를 열어 원문을 읽을지는 플러그인 밖의 결정입니다.

작성 근거: 후보 `f89b141d783d8420acc961837c686e6a52b3bbb1`, 공식 Claude 작성 guard `29913c2777d24f9985fb51d870cc2ce3`, 교정 guard `8eb1e1a332624302ac03ac90779fae09` (각각 passed/settled). 코드 리뷰는 [Claude QA 변경 리뷰](../../qa-reviews/2026-10-25-claude-qa-change-review.md)에 별도로 기록했습니다. 교정에서는 Antigravity 자동 훅의 현재 비활성 상태, 원문이 Laya 검색에 별도 색인되지 않는 경계, 비동기 큐의 `dropped` 의미, 상대 코드 링크, 미완료 호스트 QA 표시를 확인했습니다.
