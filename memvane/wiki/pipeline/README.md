# Wiki Pipeline

`.memvane/compile/wiki-pipeline.sqlite3` 단일 SQLite 원장, 단일 rename 카드 게시, 1회성 1.x → 2.0 마이그레이션을 소유한다.

- **단일 원장 (`store.py`, `schema.py`)**: `compile_jobs`, `verify_jobs`, `refresh_events`, `audit_events`, `cooldowns`, `pipeline_fences`, `publish_txns`, `card_generations`, `suppressions`, `dedup_pairs` 테이블을 트랜잭션(`BEGIN IMMEDIATE`)으로 관리한다. 큐 행 claim·반환·종결은 `queues.py`(`claim_jobs`·`finish_claim`·`recover_dead_claims`)와 `verify_queue.py`(`claim_verify_batch`·`record_verify_verdict`·`finish_verify_job`·`release_verify_claim`)가 맡는다. verify 교체본 이미지는 `verify_jobs.pending_blob`에 있다. `open_pipeline_dir`는 큐 디렉터리 옆의 같은 파일을 연다. 읽기 전용 연결은 `errors._query_only_uri`와 `PRAGMA query_only=ON`을 사용한다.
- **단일 rename 게시 (`publish.py`)**: `.publish-<txid>.tmp`(`O_CREAT|O_EXCL|O_NOFOLLOW`, `fsync`) 준비 → `publish_txns(state='publishing')` 커밋 → 호출자가 넘긴 lock(`lock_context`: `.card-write.lock` → `.topical-publish.lock`) → live 카드 CAS 순서로 진행한다. live가 이미 같은 바이트면 rename 없이 `published`다. 새 카드는 `rename_noreplace`로, 교체는 temp↔live `rename_exchange`로 넣고 밀려난 파일 SHA를 `expected_target_sha`와 대조한다. 다르면(lock 밖 편집기 저장) 다시 교환해 사람 편집을 live로 되돌리고 `conflict_user_edited`로 끝낸다. `recover_publishes`는 temp inode·SHA와 live를 대조해 roll-forward, 교환 뒤 대조, `conflict_user_edited`, `published_user_edited`(사람이 다시 편집했거나 지운 카드는 덮어쓰거나 되살리지 않는다), `aborted`로 결정하고, 열린 txn이 없는 60초 넘은 `.publish-*.tmp`를 지운다. 영속 비교는 `st_dev` 없이 `(st_ino, sha256)`만 사용한다.
- **판정 원장**: `card_generations`는 생성 카드 이력(1.x `generated-manifest.jsonl` 행 모양)을 `target_path`·`source_hash`·`canonical_key` 색인으로 담는다. `publish_card(generation=...)`의 행은 카드가 실제로 놓일 때(`published`·`published_user_edited`, 복구 포함) 같은 트랜잭션에 들어간다. `suppressions`는 같은 원문 body hash의 재추출(`verify`)과 같은 쌍의 재판정(`dedup`)을 막는 유료 호출 가드로, 키마다 마지막 값이 이긴다. `dedup_pairs`는 dedup 후보 쌍 큐다. `audit_events`는 로그 전용이며 어떤 생성·삭제 판정도 읽지 않는다.
- **1회성 1.x → 2.0 마이그레이션 (`migrate.py`)**: `generated-manifest.jsonl`·`verify-skipped.jsonl`·`dedup-skipped.jsonl`만 한 트랜잭션으로 가져오고 같은 트랜잭션에 완료 마커(`migrated_from_v1_at`)를 남긴다. 가져온 manifest 행은 `(줄 번호, 줄 SHA-256)` 키로 한 번만 들어간다. 마커 커밋 뒤 1.x 진행 중 상태(큐·claim·refresh·쿨다운·로그성 jsonl·`tombstones.jsonl`·`.handoff/`)와 위키 숨김 파일(`.first-*`·`.*.pending-*`·`.pc-*`·`.pending-ownership.json`·`.verify-swap-*`)을 지운다. `retired-wiki/`와 `wiki-retrieval/`은 보존한다.
