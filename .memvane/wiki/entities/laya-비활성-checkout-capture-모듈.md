## Summary
`core/laya_checkout_view.py`는 호출자가 보관하는 등록 JSON으로 Git checkout을 식별하는 내부 API다. 현재 hook·route·index·journal은 호출하지 않는다. `register_repository(project_root, deadline=None)`는 새 `repoId`, common Git dir 경로·dev/ino, 프로젝트 상대 위치·object format을 반환한다. `register_worktree(project_root, repository, deadline=None)`는 등록 검증 후 checkout·project·Git admin dir identity와 새 `worktreeId`를 반환한다. `capture_view(project_root, repository, worktree, deadline=None)`는 branch·HEAD·index·operation evidence와 `viewId`, `checkoutDigest`를 반환한다. `capture_matches(capture, repository, worktree, deadline=None)`는 재관측 결과가 같으면 `True`, 변경·불명·잘못된 입력이면 `False`다. `deadline`은 keyword-only이며 `time.monotonic()` 기준 절대 시각이다. 계약 문서는 `docs/development-checkout-capture.md`다.
