## Summary
`PreparedWorker(plugin_root, project, *, ready_seconds=30, run_seconds=1800)`는 `-I -B`, 비상속 descriptor, anonymous private stderr file을 사용하는 retained interpreter를 시작한다. 호출자가 생성 전에 installed root를 검증해야 하며 임의 directory를 신뢰하지 않는다.
자식은 지정 bundle을 import하고 `READY`를 보고하며 bundle의 fixture/sandbox mode를 거절한다. `GO`를 받은 뒤에만 일반 `laya_bundle_upgrade.run`을 호출한다. GO 전 EOF는 업그레이드 없이 취소한다. owner check·resource guard를 대체하지 않는다. 결과에는 일반 upgrade outcome과 state root별 실제 bound `pluginRoot`가 포함된다. deferred/refused outcome이나 다른 selected root는 `finish()` 실패다.
Readiness 상한은 60 seconds, parent run deadline 상한은 2100 seconds이며 자식은 일반 1800-second upgrade alarm을 사용한다. native SQLite call 내부에서는 alarm이 즉각 중단을 보장하지 않는다.
