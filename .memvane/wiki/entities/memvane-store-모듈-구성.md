## Summary
`memvane/store/README.md`: `checkout_view.py`는 caller가 보관하는 저장소·워크트리 등록 JSON과 Git checkout capture API다. 경로·dev/ino, ref·HEAD·index·operation을 재검증하고 view identity를 계산한다. view store가 binding·capture를 검증할 때 쓰며, recall pin과 sync 게시가 이 경로로 checkout을 관측한다(`docs/development-checkout-capture.md`). 관측 한 번은 checkout을 두 번 읽어 대조하고 git 자식 12개를 띄운다(`--version` 확인은 그중 한 번). macOS의 `/usr/bin/git` shim이 넘기는 실제 git 경로를 그 capture의 fingerprint가 증명했으면 그 capture 안에서는 shim을 거치지 않고 그 경로를 실행한다. 등록(`register_*`)과 fingerprint가 서지 않는 capture는 PATH의 `git`을 쓴다. `blob_store.py` / `blob_schema.py` / `blob_values.py`는 schema3 view store의 내용 층으로, private Git-blob 형식의 wiki admission·불변 body/recipe/profile/set·metadata provenance를 담당한다. 원문 body API는 없다. `put_fingerprint`·`put_attestation`에 넘기는 지문·receipt는 호출자의 증거 주장이다. schema3 sync 게시는 `ingest_attested_card`를 쓴다: 저장소가 카드 frontmatter를 recall의 신뢰 규칙(`legacy_card_evidence`)으로 직접 판정해 통과한 카드에만 `legacy_unbound` 지문의 `legacy_verified` attestation을 붙이고, 현재 HEAD를 과거 compile commit으로 쓰지 않는다. 구조 제약·의미 검증·API·상한은 `docs/development-blob-candidate.md`에 있다.
