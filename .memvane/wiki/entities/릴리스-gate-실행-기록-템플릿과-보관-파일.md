## Summary
`docs/templates/release-gate-run.md`(Release gate run record — TEMPLATE)는 작성 전에 private release evidence store에 복사하는 빈 양식이다(one directory per version). 작성본은 smoke machine과 그 account 이름을 담으므로 절대 커밋하지 않는다. 규칙은 `../release.md`(`docs/release.md`)에 있다. 상태는 `PASS`, `FAIL`, `BLOCKED`, `NOT RUN`이며 missing 또는 partial result는 절대 `PASS`가 아니다.
기록 옆에 보관하는 파일:
- `gate.json`: commit, sessions, 모든 item의 status와 note. `scripts/release_smoke.py verdict`가 쓴다.
- `gate-after-release.md`: 그 verdict의 RS-* 표.
- `plan.json`, `prompt-*.txt`, `fixture-tree/`: run의 synthetic project와 prompts.
- `account-prep.txt`: read-only account checks와 사용자가 확인하는 items.
- `identity.json`: release commit 대비 installed plugin files.
- `model-url.json`: pinned model address의 size와 sha256.
- `events-fixture.jsonl`: project event rows의 복사한 fields(prompt나 card text 없음).
- `aged.json`: update 전후의 long-lived install, stored and live device numbers 포함.
- `slo-*.txt`: working machine installs의 SLO summaries(day 0, 24 hours, 7 days).
- `ps-before.txt`, `ps-after.txt`: update 전후 version별 MemVane processes.
