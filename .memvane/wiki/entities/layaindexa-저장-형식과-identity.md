## Summary
현재 구현은 `core/laya_*.py`이며 선택된 Laya route에서 사용한다. 색인 DB는 `core/laya_index_a.py`의 `LayaIndexA`(A-int)가 소유한다. `LayaIndexA.SCHEMA_VERSION = 6`은 SQLite `PRAGMA user_version`으로 확인하며 검색 세대 ID와 별개다. installer는 설치별 `~/.local/state/laya/<install id>`를 만들며 install id는 32자리 hex, 권한은 0700이다. identity는 안정적인 프로젝트 등록 ID·별도 worktree incarnation ID·승인된 collection/role로 구성하며 branch 이름이나 moving HEAD를 사용하지 않는다. 승인 범위 밖 경로는 자동 등록하지 않고, 제품 이름 변경을 이유로 발행된 스키마·데이터 경로를 조용히 변경하지 않는다.
