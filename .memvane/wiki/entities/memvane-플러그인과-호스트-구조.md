## Summary
MemVane은 색인 기반 자동 컨텍스트 주입 플러그인이다. 플러그인 id는 `memvane`, marketplace는 `memvane-marketplace`이며 Claude Code · Codex · Hermes Agent · Antigravity(Gemini)를 지원한다. 사용자 안내는 `README.md`에 있다. 플랫폼 무관 공통 로직은 `core/`, Claude/Codex/Gemini 디스패처는 `hooks/`, Hermes Agent adapter는 `hermes_adapter/`에 둔다. Hermes hook은 pre_llm_call/on_session_start/pre_tool_call/post_tool_call이며 `post_tool_call`은 observer-only다. 인덱스·임베딩 런타임은 Laya가 소유한다(`laya_resident_service.py`).
