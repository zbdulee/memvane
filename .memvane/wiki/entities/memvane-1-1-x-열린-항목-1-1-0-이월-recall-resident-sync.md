## Summary
`docs/ROADMAP.md` 「1.1.x 열린 항목 (1.1.0 이월)」 중:
- **recall resident/API 방식.** 1.2 후보.
- **recall 순위.** 프롬프트 앞 일반 지시문("도구는 쓰지 말고 답만 해 줘.")이 semantic 순위를 끌어 드문 토큰이 정확히 일치하는 카드가 상위 3장에서 빠진다. 지시문을 빼면 그 카드가 1위. 긴 질의의 lexical 일치 비중과 fusion 가중을 조사한다.
- **resident 번들 인계.** 번들 확인이 `codex plugin list --json`을 10초 안에 기다리는데 콜드 실행은 60초를 넘는다. 실패 결과가 1시간 캐시되어 호스트 갱신 뒤 옛 resident가 최대 1시간 남는다.
- **세션 밖 변경의 즉시 반영.** 에디터 편집·`git pull`·checkout은 다음 SessionStart, 프로젝트 안 편집(`index`), Claude의 성공한 Bash(`file-change-event`) 때 full-scan sync로 반영된다. UserPromptSubmit은 sync를 깨우지 않는다. 후보: (A) resident가 OS 파일 이벤트(macOS FSEvents)로 감시, (B) recall hook이 sync 요청을 남기고 짧은 간격 중복 합침, (C) resident 주기 점검. A 기본, B 보조로 검토.
- **resident 상시 기동(OS 로그인 항목).** 지금은 hook이 처음 필요할 때 띄워 재부팅 뒤 첫 프롬프트가 기동·모델 로드를 기다리고, 죽으면 다음 hook 전까지 되살리는 주체가 없다. macOS launchd 사용자 agent(`~/Library/LaunchAgents`, KeepAlive), Windows 작업 스케줄러 로그온 작업 또는 시작 프로그램, Linux systemd `--user` unit. 검토: setup 명시 승인으로만 등록·해제, 플러그인 제거 시 삭제, 버전 변경 시 실행 경로 갱신(번들 인계와의 관계), 메모리(resident 약 350MB, 학습 resident 수 GB), hook 기동과의 공존. 새 로그인 항목과 설정 키는 사용자 결정 사항.
