## Summary
`scripts/release_coordination.py`는 maintainer 설치·업그레이드를 조정하며 product hook은 호출하지 않는다. 호출자는 신뢰하는 project/state mapping과 사용자 전역 development `Lease`를 확보하고 설치·업그레이드 전에 development hold를 확인한다. `coordinate_release(states, *, install_both, prepare_worker)`는 비어 있지 않은 mapping으로 최대 32 projects·128 distinct state roots를 받는다. 기존 canonical private state directory는 현재 UID 소유·0700이어야 한다. `bundle-auto-upgrade.lock`은 현재 UID 소유·0600·single-link 정규 파일이며 없으면 생성하고 삭제하지 않는다. 모든 잠금을 nonblocking으로 확보한 뒤 `install_both()`를 한 번 호출한다. busy·unsafe root는 설치 전에 거절한다. callback은 두 supported host 설치·version/source commit 검증과 유한 timeout을 책임지며 lease를 재획득하지 않는다. callback 반환값은 installation attestation이 아니다.
