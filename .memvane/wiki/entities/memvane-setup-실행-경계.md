## Summary
setup은 marketplace에 설치된 host plugin으로 실행하며 plugin 등록과 hook trust는 별도 host 작업이다. `ROOT`는 검증된 `CLAUDE_PLUGIN_ROOT` 또는 `PLUGIN_ROOT`, 아니면 이 `SKILL.md` 절대 경로에서 두 디렉터리 위로 구하고 `ROOT/core/setup_entry.py`를 확인한다. 대상 프로젝트 git root로 추론하지 않는다. 모든 action은 `python3 "$ROOT/core/setup_entry.py" <action> --project "$PROJECT_ROOT" ...`로 실행한다. 설치 트리에서 plain `python3`로 plugin module을 import하면 `__pycache__`가 생겨 `installed_file_set_not_exact_commit`으로 거절되며 `detail.unexpected`에 표시된다.
