## Summary
`tests/structure/README.md`: `context-map.json`은 `memvane/`, `entry/`, `hermes_adapter/`의 Python 모듈을 도메인·계층별로 분류하고, `pinned_paths`는 host 진입점, manifest, provider와 worker 등 필수 경로를 기록한다. `structure_guard.py`는 정적 import 그래프, 함수 크기와 고정 경로를 조사하며 도메인 API 경계와 기준선을 함께 관리한다. `v1_guard.py`는 G1~G8을 `issues`에 보고하고, 엄격 규칙은 `strict_issues`에 따로 보고하며 `--strict`를 줄 때만 종료 코드에 반영한다.
