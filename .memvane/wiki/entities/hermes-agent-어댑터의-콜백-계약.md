## Summary
Hermes는 Claude/Codex hook JSON을 읽지 않고 `plugin.yaml`, `__init__.py`, `hermes_adapter/plugin.py`, `hermes_adapter/core_bridge.py`를 사용한다. 모든 callback은 `laya_index_host_route.select_route`를 거치고 selected route에서 `laya_host_response.serve_selected`를 호출한다. 매핑은 `pre_llm_call` → `recall_context` → `recall`, `on_session_start` → `session_update` → `update-queued`, `pre_tool_call` → `pre_edit_gate` → `gate`, `post_tool_call` → `post_edit_sync` → `posttool`, `index`다. `post_tool_call`은 observer-only로 sync wake를 기록하며 Claude/Codex posttool context injection과 동등하게 설명하면 안 된다.
