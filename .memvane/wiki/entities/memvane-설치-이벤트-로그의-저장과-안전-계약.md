## Summary
선택된 route의 install journal directory에 `events.jsonl`을 둔다. directory는 owner-only `0700`, 파일은 `0600`이다. 4 MiB 초과 시 `events.jsonl.1`·`events.jsonl.2`로 순환해 최대 세 파일을 유지한다. selected route가 없으면 기록하지 않는다. `logs` skill은 로컬에서 읽는다. hook·background 결과, reason codes, 시간, session id, recall 카드 경로·content hashes, compile·verification 카드 경로·제목, index publication·bundle upgrade를 기록한다. hook 실패는 exception class·code location만 기록한다. 기본 prompt·extractor stderr는 SHA-256과 문자 수로 기록한다. `MEMVANE_EVENT_LOG_PROMPTS=1`이면 prompt 첫 1000 characters와 extractor stderr 마지막 1000 characters를 `text`에 추가한다. token, password, secret, credential, API key, authorization, cookie 관련 이름의 필드는 제거한다.
