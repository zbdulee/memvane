## Summary
`memvane/sync/README.md`: `sync.profile` 이벤트는 선택된 schema3 sync의 scan·plan·coverage·provider·storage·publish별 누적 밀리초와 호출 수를 한 줄에 기록한다. 본문과 경로는 기록하지 않는다. scan은 위키 목록·카드 읽기·원문 관측을, plan은 fill 계획 생성(상태·fill 내부 호출 포함)을, coverage는 대상의 embedding set 확인을, provider는 embedding 호출을 잰다. storage는 `fill_view`를, publish는 세대 준비·게시를 잰다. storage 시간에는 그 안의 provider 호출과 내부 계획 확인이 포함되므로 단계 시간을 합산하지 않는다. 이벤트의 `ms`는 schema3 실행 전체이며 후속 discovery는 포함하지 않는다.
