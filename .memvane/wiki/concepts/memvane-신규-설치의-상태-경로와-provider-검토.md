## Summary
온보딩은 host가 실제 로드한 exact commit·source checkout·embedding dimension을 확인한다. 새 private state directory는 fresh 32-hex install ID를 사용하는 `~/.local/state/memvane/<install id>`여야 하며 다른 경로는 `unsupported_state_root_creation`으로 거절한다. provider digest는 이 경로에 의존한다. `plan-fresh-wiki-origin`과 `review-index-provider --provider-dimension <n>`으로 검토하고 두 exact proposal digest·collection roots·installed commit·model/native identity·resource admission을 제시한다. `--provider-model-file`은 runtime 자체 모델이어야 하며 아니면 `provider_review_model_not_laya_runtime`이다. runtime 누락·변경은 `provider_review_laya_embed_runtime_missing` / `_corrupt`로 거절한다.
