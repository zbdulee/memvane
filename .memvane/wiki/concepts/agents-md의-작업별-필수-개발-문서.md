## Summary
`CLAUDE.md`는 Claude Code(claude.ai/code)가 이 저장소에서 작업할 때 따를 필수 문서를 안내하며 `@docs/dev/contexts/working-rules.md`를 포함한다. `AGENTS.md`는 Codex와 다른 coding agent에게 같은 안내를 제공한다. 작업 시작 시 공통 개발 규칙 `docs/dev/contexts/working-rules.md`를 반드시 읽는다. 해당 작업에 적용되는 context 문서도 수정 전에 직접 읽는다. 링크 자체가 문서를 자동으로 불러오지는 않는다. 작업 경로·주제별 문서: `memvane/<domain>/`은 해당 도메인의 `README.md`를 읽는다. `hooks/`와 `hermes_adapter/`는 `memvane/host/README.md`와 `memvane/route/README.md`를 읽는다. 설치와 provider 작업은 `memvane/install/README.md`와 `memvane/provider/README.md`를 읽는다. `skills/`는 `docs/dev/contexts/skills.md`를 읽는다. manifest·릴리스는 `docs/dev/contexts/release.md`를 읽는다. 표에 없는 경로도 공통 규칙을 따르며, 관련 context와 그 문서가 가리키는 개발 문서를 찾아 읽는다.
