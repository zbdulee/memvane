## Summary
Checkout capture는 원문 본문을 읽지 않는다. HEAD와 index가 같아도 unstaged 파일 bytes는 다를 수 있어 실제 데이터 게시에는 별도 source scan manifest가 필요하다. 현재 원문·카드 내용·삭제 조건은 이 API만으로 증명할 수 없다. primary index를 직접 읽어 v2·v3·v4 framing과 checksum을 확인하며 Git index 로더를 호출하지 않아 split index 거절 시 shared index의 mtime을 갱신하지 않는다. shared 내용까지 증명할 수 없으면 `split_index_unsupported`로 거절한다. `capture_matches`는 evidence 타입과 입력 digest도 검증한다. 새 저장소 schema·reader endpoint·view 검색 선택은 별도 계약이다. 검증은 `test/laya-checkout-view.test.mjs`와 임시 Git fixture를 사용하며, 호스트 route 회귀는 `test/laya-index-host-route.test.mjs`로 확인한다.
