## Summary
`docs/development-resource-safety.md`: 각 run은 자체 `runs/ID` directory, checkpoint, samples, 임시 runtime root, process tree를 가진다. exclusive run은 `active.json`, shared test는 slot별 `active-test-slot-N.json`을 기록한다. shared test는 unsettled `active.json`이나 자기 slot 기록을 거절하고, exclusive job은 모든 unsettled 기록을 거절한다. 이전 checkout은 `active.json`만 읽는다.
영구 development log directory 아래 private `runs/ID/samples.jsonl`은 system pressure/headroom/swap/load와 각 child의 CPU/RSS/start identity를 기록하며 command arguments나 environment secrets는 기록하지 않는다. `checkpoint.json`과 `active.json`(또는 slot 기록)은 passed, failed, stopped, unsettled cleanup을 구분한다. resource stop은 완료가 아니다. root identity 불명·cleanup 실패·killed supervisor는 unsettled checkpoint를 남기고 수동 점검 전까지 다음 guarded job을 차단한다. child data, test logs, partial backups는 보존되며 cleanup은 이를 삭제하거나 운영 DB·모델을 rollback하지 않는다. 갑작스런 OS 장애로 checkpoint 쓰기가 중단될 수 있으며 중단된 run은 점검해야 하고 passed로 재표기하지 않는다. 중단된 test log와 partial backup은 자체 완료 증거가 있을 때까지 미완료다.
