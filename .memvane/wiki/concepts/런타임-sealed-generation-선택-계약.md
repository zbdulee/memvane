## Summary
Runtime producers는 seal·copy·reactivate한 generation을 반환하며 runtime lock 해제 후 global `active.json`을 다시 선택하지 않는다. bundle worker는 해당 generation을 첫 provider review와 active, bound, inactive, fenced-recovery reviews에 전달한다. `select_generation()`은 현재 owner의 private runtime `generations/` 바로 아래 canonical path만 허용하고 complete sealed file inventory와 ownership을 재검사한다. active/previous pointers는 읽거나 쓰지 않는다. 누락·변경·링크·외부 generation은 거절한다. explicit generation 없는 provider review는 active-runtime selection을 유지한다. generation 선택은 sealed bytes의 증거이며 native execution test는 아니다.
