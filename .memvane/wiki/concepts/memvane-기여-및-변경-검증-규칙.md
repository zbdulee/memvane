## Summary
MemVane 변경 전에는 기존 이슈에서 같은 문제를 검색한다. 공통 로직은 가능한 한 `core/`에 호스트 중립적으로 두고 Claude Code, Codex, Hermes adapter 영향을 확인한다. 프로젝트별 경로, credentials, logs, user content를 추가하지 않는다. 동작 변경에는 결정적 회귀 테스트를 추가하거나 갱신한다. 리뷰 요청 전 `npm test`와 `git diff --check`를 실행한다. Live qmd 또는 host CLI 검사는 선택 사항임을 표시하며 결정적 테스트를 대체하지 않는다. PR은 범위가 명확한 브랜치를 사용하고 사용자에게 보이는 동작, 지원 호스트, 검증 근거를 설명한다. manifests, hooks, public docs 변경은 영향을 받는 설치 및 런타임 계약을 명시한다. 기준 문서는 CONTRIBUTING.md다.
