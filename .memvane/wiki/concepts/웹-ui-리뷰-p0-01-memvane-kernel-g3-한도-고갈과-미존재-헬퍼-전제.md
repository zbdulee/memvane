## Summary
[P0-01] §5.1, §8.2. `tests/structure/v1_guard.py:1154-1162`의 `G3`는 `memvane/kernel/`에서 `__init__.py`를 제외해 ≤ 14개, 총 ≤ 1,500줄, 파일당 ≤ 250줄을 허용한다. `memvane/kernel/*.py`는 14개 모듈 / 총 1,499줄로 여유가 0개·1줄이다. 2줄 추가 시 `G3`가 실패한다. `memvane/kernel/memvane_paths.py:17,36-43,74,93,140,146,166`은 `import pwd`, `os.getuid()`를 사용하며 `support_base()`·`cache_base()`가 없다. `state_base`, `support_base`, `cache_base`, 잠금, PID 확인, detached spawn을 `kernel/`에 두는 초안 대신 `ui` 전용 브라우저 오픈·프로세스 확인·TCP 소켓·`server.lock`은 `memvane/ui/` 내부의 `platform_io.py` 등에 격리하라고 권고한다. 1.x에는 커널 증설을 전제하지 않고 Windows 포팅에서 `G3` 상한 또는 유틸 이관을 별도로 다룬다.
