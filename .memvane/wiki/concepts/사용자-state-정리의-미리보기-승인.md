## Summary
`memvane/install/README.md`: `state_cleanup.py`(`install.api.state_cleanup`, setup action `state-cleanup`)는 사용자 state의 미리보기와 승인 삭제를 맡는다. 미리보기는 아무것도 쓰지 않는다. setup 진입점은 삭제 대상 목록으로 `previewSha256`을 내고, 승인(`--approve-state-cleanup <previewSha256>`)은 지금의 목록이 그 값과 같을 때만 지운다(다르면 `state_cleanup_preview_changed`로 거절하고 지금의 미리보기를 낸다). 승인된 목록(`only`)에 없는 대상은 `not_previewed`로 남긴다.
- 기본 범위는 `installs/`의 설치 state root다. 설치의 `route.json`이 가리키는 프로젝트 폴더가 있고 그 폴더의 `route.json`·`selection.json`이 이 state root를 가리키지 않으며 `initial-builds` 포인터도 없을 때만 `remove released`다. 프로젝트의 `route.json`(`stateRoot`)이나 `selection.json`(`installId`)이 이 설치를 가리키면 `selected`(빌드 포인터는 온보딩 뒤에도 남는다), 프로젝트 포인터 없이 빌드 포인터만 가리키면 `building`이다. `selected`, `building`, `project_unreachable`(분리된 볼륨일 수 있다), `pointer_unreadable`, `build_pointer_unreadable`, `unrecognized`는 남긴다.
- 임베딩 runtime 세대 정리(`provider.api.collect`)는 app 층 setup 진입점이 같은 결과의 `indexRuntime`에 합친다.
