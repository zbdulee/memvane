## Summary
`search_exact(pin, query_vector, limit, *, profile_id, max_float_work=4000000, deadline_seconds=2, path_prefixes=None, excluded_paths=None)`는 봉인된 recipe/profile만 쓴다. lexical-only 세대는 `vector_coverage_absent`로 거절한다. query vector는 profile dimension과 같은 유한 숫자 list/tuple이며 bool·zero norm은 거절한다. 카드의 모든 chunk cosine 최댓값으로 점수를 매기며 동점은 UTF-8 binary path 오름차순이다. ANN·chunk 절삭은 없다. view·자격·path 필터 후 각 path의 `chunk_count × dimension` 합을 계산한다. `max_float_work`는 양의 정수이고 기본 4,000,000이며 같은 blob의 여러 path도 각각 계산한다.
