## Summary
`docs/release.md` RS-core: recall은 row가 `semantic: complete`이고 candidate가 하나 이상이며, 대상 카드 hash로 served되거나 실제 zero-card selection이면 통과다. long prompt(12,000 character)는 query chunks가 최소 2개여야 한다. 시간 임계값은 version line의 첫 run에서 정하며 그 run은 판정 대신 값을 기록한다. host outage, expired login, unreachable account는 `BLOCKED`이고, 사용자가 hook trust를 승인하기 전 모든 Codex 항목도 `BLOCKED`다. tool은 prompt만 입력하며 directory trust나 edit permission 화면은 operator가 해당 세션에서 답한다. 프로젝트 learning은 run이 켜지 않는 한 off이며 off면 RS-EDIT의 `learning.capture` 부분은 `NOT RUN`이다. edit 요청 문단은 edit recall을 시작하는 최소 edit보다 길다.
