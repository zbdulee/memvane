## Summary
새 벽시계 단정을 쓰기 전에 회귀를 개수·상태(프로브 개수, `res.signal`, 완료 마커 존재)로 표현할 수 있는지 먼저 확인한다. `spawnSync`는 timeout 시 `status: null`·`signal: 'SIGTERM'`을 반환하므로 `notEqual(status, 0)`은 공허하게 통과한다. 폴링 대기에 `execFileSync('sleep', …)`를 쓰지 않고 `waitUntil` / `waitUntilAsync`를 쓴다. 동기 sleep은 SIGCHLD 수확을 막아 좀비를 살아 있는 것으로 읽게 만든다. `execFileSync`에는 반드시 `encoding:'utf8'`을 준다. 생략하면 Buffer가 반환되어 `.trim()`에서 에러가 난다. 테스트는 임시 HOME과 `realpath`로 푼 fixture state root를 쓰며 제품 데이터와 라이브 로그에 닿지 않는다. `__pycache__`는 `.gitignore` 처리되어 있다. node 테스트 프로세스 안에 http 서버를 띄우지 않는다. stub 서버가 필요하면 Python driver(스레드 서버 + subprocess)에서 띄운다.
