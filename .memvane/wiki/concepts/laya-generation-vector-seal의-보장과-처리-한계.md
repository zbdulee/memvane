## Summary
`seal_generation`은 DB의 prepared generation eligible membership을 읽고 모든 member의 complete cached chunk set을 요구한다. 누락은 `vector_coverage_incomplete`이며, 충족하면 `gen_vector_rows`와 seal을 기록한다. generation별 idempotent이고 모델 실행이나 source read가 없다. 전체 generation을 한 transaction에서 순회하되 row를 streaming한다. `MAX_GENERATION_SEAL_ROWS = None`이므로 전체 generation row 제한은 없다. `MAX_CANDIDATES` (20,000)는 문서 하나의 chunk set과 explicit query budgets를 제한한다. `search_exact`는 query마다 scope 내 모든 chunk를 scoring하며 hook deadline과 명시적 caller budget의 제한을 받는다.
