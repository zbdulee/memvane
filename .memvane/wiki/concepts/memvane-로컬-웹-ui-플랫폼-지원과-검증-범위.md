## Summary
단일 웹 UI 코드베이스의 장기 지원 대상은 macOS · Linux · Windows(네이티브 및 WSL) · 원격 SSH(포트포워딩)다. Phase 1~3의 실행·검증 범위는 Apple Silicon macOS · Linux · WSL(Linux 백엔드 + Windows 브라우저)이다. 네이티브 Windows 백엔드는 `event_log`, `runtime`, `resident`, `learning`, `kernel`의 POSIX 의존인 `fcntl`, `pwd`, `os.getuid()`, `AF_UNIX` 제거를 선행 조건으로 둔다. `memvane/ui/`는 처음부터 Windows 호환 규칙(§8)을 적용한다.
