## Summary
`docs/privacy.md`에 따르면 Optional wiki compile은 온보딩된 프로젝트의 minimal settings로 활성화된다. 후보 생성과 검증에 쓰는 configured host CLI에는 선택된 Markdown 원문, bundled card-writing rules, 설치 이벤트 로그의 최근 `wiki` events(카드 경로와 제목), 유사 wiki 카드가 전달된다. built-in adapters는 도구를 끈 격리된 임시 작업 디렉터리에서 nested host CLI의 파일시스템 접근을 제한한다. 제공자 전송 여부는 host CLI와 계정 설정에 따르며 제공자의 데이터 정책이 적용된다. 민감한 자료가 있는 프로젝트는 온보딩 전에 host provider의 privacy policy를 검토한다.
