## Summary
온보딩된 프로젝트의 minimal settings는 optional wiki compile을 켠다. compile은 선택된 Markdown 원문, bundled card-writing rules, install event log의 최근 `wiki` events에 담긴 카드 경로·제목, 유사 wiki cards를 configured host CLI에 전달해 후보를 생성·검증한다. CLI와 계정 설정에 따라 내용이 제공자에게 전송될 수 있다. built-in adapters는 도구를 비활성화한 isolated temporary working directory에서 실행하지만 제공자의 데이터 정책은 바뀌지 않는다. 민감한 프로젝트의 온보딩 전 host provider의 privacy policy를 검토한다.
