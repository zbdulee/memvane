## Summary
`docs/release.md`의 `P2 focused`는 변경 영역과 영향 범위를 Python 3.13 및 `/usr/bin/python3` (3.9)에서 검사하고 guard run ids를 남긴다. `P3 PR CI`는 macOS arm64의 시스템 Python 3.9 작업을 포함해 모든 작업이 성공해야 하며 run URL을 남긴다. `P4 full suite`는 실행 중 수정하지 않는 전용 worktree에서 최종 커밋에 `npm test`를 실행하고 guard run ids 4개를 남긴다. `P6 independent review`는 최종 패치에 병합을 막는 지적이 없음을 review document로 확인한다. `P4` 또는 `P5` 이후 최종 커밋이 바뀌면 새 커밋에서 해당 검사를 다시 실행한다.
