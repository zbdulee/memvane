## Summary
명시적 철회 요청에는 프로젝트 root와 state directory를 밝히고 `restore-index-origin --project "$PROJECT_ROOT" --state-root "$STATE_ROOT" --approve-index-origin-restore`를 실행한다. ledger·private install journal·reviewed route가 일치하고 selected MemVane write가 없어야 복원한다. `legacy_restored`·`legacy_selected`는 선택 해제, `blocked`와 `rollback_forward_only`는 새 쓰기 때문에 선택 유지다. `recovery_required`는 bounded attempt 한 번 후의 phase이며 반복 재시도하지 않는다. restore는 선택이 게시한 exact route file만 제거하고 candidate stores·ledger·marker를 유지한다. `qmd-cutover.json`이 남은 state root는 `qmd_origin_detach_required`로 거절하므로 중단한다.
