## Summary
`tests/structure/README.md`: G8은 시험 파일의 `patch` 대상이 실제 모듈·속성인지 본다. `test/`, `tests/`, `memvane/**/tests/`의 Python 파일을 읽고, `test/` 밖에서는 `mock.patch('…')`와 문자열 전체가 `memvane.` 점 경로인 값(patch 대상 표)도 대상으로 읽는다. 시험 G1(`--tests`)은 시험이 이름을 부르는 범위다. `memvane/<A>/tests/**`는 `memvane.<A>.*`, `memvane.kernel.*`, `tests.support.*`, 다른 도메인의 `api`·`types`만, `tests/<X>/**`는 `api`·`types`, kernel, `tests.support.*`와 자기 폴더만 부른다. import 문, 리터럴 `import_module`·`__import__` 인자, `patch`·`patch.object` 대상, 문자열과 `.mjs` 안의 Python import·patch 문장을 모두 센다. 다른 도메인 api의 `_` 이름은 `private_api`, 없는 `memvane.` 모듈은 `missing_module`이다. 예외는 `_TEST_G1_EXCEPTIONS`(시험 파일, 점 이름) 표에만 두고, 파일이 있는데 쓰지 않는 예외는 `unused_exception`이다. 가드 자기시험의 합성 소스가 있는 `tests/structure/`는 시험 G1을 보지 않는다. 출력 `tests`에는 파일별·폴더별 시험 G1·G8·미해석 patch 대상 수가 있고, 표준 라이브러리 대상(`time.time` 등)은 `external_patch_targets`로 따로 센다.
