## Summary
host plugin update 뒤 SessionStart worker가 memvane-db 설치를 새 bundle로 자동 이동하므로 통상 `upgrade-*`를 실행하지 않는다. host marketplace clone은 HEAD가 installed commit이고 tracked files가 clean일 때만 쓰며 provider review에서 bundle file paths만 바뀐 경우에만 허용한다. 완료 전 마지막 published index는 읽기 전용이고 sync·compile·index wakes는 기다린다. `provider_changed_rebuild_required`, `older_host_bundle`, marketplace source refusal은 기존 bundle 유지 사유다. provider 변경은 reviewed rebuild 또는 fresh provider review를 동반한 explicit upgrade가 필요하다. `active_upgrade_restored`는 소유자가 `restore-active-index-bundle`을 실행했다는 뜻이며 이전 bundle을 유지한다. 원인 해결 후 fresh provider review와 `upgrade-active-index-bundle`로 이동한다. 더 새롭거나 재추출된 bundle은 통상 자동 업그레이드한다.
