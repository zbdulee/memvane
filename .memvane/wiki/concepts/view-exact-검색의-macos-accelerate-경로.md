## Summary
macOS의 Accelerate 경로는 pin의 member vector를 store에서 대량으로 읽는다. 상한은 중복 blob을 한 번씩 센 40,000 vector와 입력 128 MiB다. 4,096행마다 deadline을 확인하고 float32를 double로 넓혀 chunk별 cosine을 계산하며 모든 행의 개수·seq·길이·유한성·양의 norm을 확인한다. 상위 60장(limit가 더 크면 limit장)의 set·행 digest를 전체 검증하고 기존 Python 함수로 재채점하며 나머지 digest 검증은 게시 봉인에 맡긴다. `MEMVANE_VECTOR_ACCEL=off`, 비-macOS, 라이브러리 로드·자기 시험 실패에서는 순수 Python 경로를 쓰며 `max_float_work`(기본 4,000,000)는 이 경로의 상한으로 고유 blob의 `chunk_count × dimension` 합계를 계산하고 모든 digest를 검증한다. recall 이벤트는 `vectorKernel`·`vectorSource`, `vectorRows`·`vectorVerified`, `vectorLoadMs`·`vectorScanMs`·`vectorVerifyMs`와 기존 `vectorReadMs`·`vectorUnpackMs`·`vectorDotMs`를 기록한다.
