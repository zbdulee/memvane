## Summary
`npm test`와 `npm run test:focused -- test/NAME.test.mjs`는 `scripts/development_guard.py`를 거쳐 `node --test --test-concurrency=1`과 QMD fixture/log isolation을 유지한다. 전체 검사는 1,800초, focused 검사는 기본 900초 예산이다. 백업·해시는 `npm run dev:guard -- --kind backup -- COMMAND ...` 또는 `--kind hash`를 사용한다. wrapper는 shell 명령을 구성하지 않고 argv를 직접 실행한다. 일반 모의·회귀·통합 검사(`--kind test`, CI 포함)는 모델 작업의 OS pressure·CPU/RSS·headroom·swap·load admission 제한을 적용하지 않는다. 전역 lease 1개, 파일 병렬도 1, 유한 시간, process-count 제한, ownership 검증과 abnormal-child cleanup은 유지한다. 실제 모델 로딩·학습은 `--kind model-test`를 사용하며 explicit calibration envelope도 자원 제한을 유지한다. 이 구분은 설치된 runtime learning admission을 바꾸지 않는다.
