## Summary
`npm test`와 `npm run test:focused -- test/NAME.test.mjs`는 `scripts/development_guard.py`를 통해 `node --test --test-concurrency=1`과 QMD fixture/log isolation을 유지한다. 전체 예산은 1,800초, focused 기본값은 900초다. 백업·해시는 `npm run dev:guard -- --kind backup -- COMMAND ...` 또는 `--kind hash`를 사용한다. wrapper는 shell 명령 구성 없이 argv를 직접 실행한다. 일반 검사 `--kind test`(CI 포함), 원격 리뷰 `--kind review`, 해시·staging `--kind hash`는 모델용 자원 admission 제한을 적용하지 않지만 전역 lease·파일 동시성 1·유한 시간·프로세스 수·소유권·cleanup 검사는 유지한다. 실제 모델 로딩·학습 검사는 `--kind model-test`이며 calibration envelope도 자원 제한을 유지한다. 설치된 runtime learning admission은 바뀌지 않는다.
