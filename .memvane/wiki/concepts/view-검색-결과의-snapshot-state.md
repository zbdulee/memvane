## Summary
`snapshot_state`는 `published_snapshot`(caller와 봉인 시점 checkout digest 동일), `stale_snapshot`(digest가 다르지만 HEAD가 같거나 원래 HEAD가 현재 HEAD의 조상), `lineage_changed`(원래 HEAD가 현재 HEAD의 조상이 아님), `lineage_unverified`(HEAD가 없거나 유한한 Git 계보 확인으로 판정 불가)다. 이 상태는 해당 view의 마지막 게시 snapshot을 설명하며 최신 원문 일치를 보장하지 않는다. seal·receipt·지문·검색 자격은 구조적 commitment이며 compiler 실행, 실제 원문 관측, 인용 정확성, 운영 owner 권한이나 삭제 권한을 증명하지 않는다. pin 이후 같은 view의 head가 바뀌면 `view_head_changed`로 거절하며 view 행 GC는 head와 직전 세대를 보존한다.
