## Summary
`docs/plans/2026-11-01-memvane-db-git-blob-model.md`는 GC에 새 incarnation으로의 mark-and-copy compaction을 제안한다. 실행 중인 DB에서 참조가 끊긴 행을 수정하는 방식 대신 새 DB로 보존 대상을 복사한다. 보존 기간이 확정되기 전 자동 GC는 비활성이라는 제안이며 사용자 확인 대상이다. GC는 기존 UPDATE/DELETE/REPLACE 방지 trigger를 해제하지 않고 모델을 로드하지 않는다.
