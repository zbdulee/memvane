## Summary
로컬 ignored `.development-hold.json`은 일반 검사·백업·해시를 포함한 모든 child job을 차단한다. 해제에는 명시적 사용자 승인이 필요하며 CLI 우회는 없다. child 실행 전 exit 75와 `work_remains_on_hold`를 반환한다. 승인은 자원·소유권·cleanup 검사를 우회하지 않는다. sampler-only는 child를 실행하지 않으며 이전 작업의 완료 증거가 아니다. 일반 focused 검사(`--kind test`)는 worktree·agent 전체에서 최대 3개이며 파일 동시성은 1이다. `npm test`의 `--exclusive`, backup, hash, model-test, review, sampler-only, calibration envelope는 단독 실행한다. 자리 부족은 exit 75와 `development_job_busy`이며 queue 없이 재시도한다. `npm run test:guard-unit`만 실제 host probe·모델 작업 없는 작은 Python 안전 검사의 bootstrap 예외다.
