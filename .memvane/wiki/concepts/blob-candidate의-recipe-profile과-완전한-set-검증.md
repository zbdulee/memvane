## Summary
chunk recipe는 tokenizer/chunker artifact SHA, token window/overlap/search window, `utf16-code-unit` offset, `qmd-markdown-v1` heading 규칙, `blob-input-v1`을 묶는다. title은 pinned `laya_qmd_chunking.mjs`의 ECMAScript 공백·줄 경계 규칙을 따른다. heading 없는 카드의 title은 synthetic filename의 SHA이므로 rename해도 입력이 바뀌지 않는다. 문서 입력은 `title: {title || 'none'} | text: {chunk.text}`, query 입력은 `task: search result | query: {text}`다. profile은 model ID, model bytes SHA, embedding fingerprint, dimension·cosine·문서/query input recipe를 묶는다. 등록 spec은 실제 실행 호환성의 증명이 아니다. chunk는 연속 seq·증가 position을 가지며, text는 카드의 정확한 UTF-16 slice이고 text SHA가 일치해야 한다. vector는 chunk/input SHA, little-endian float32 길이, 유한 값, nonzero norm을 검증한다. lookup·replay 확인·삽입은 한 `BEGIN IMMEDIATE` transaction에서 수행한다. 동일 replay는 no-op이고 다른 replay는 conflict이며 덮어쓰지 않는다. 실패 시 부모·자식을 모두 rollback한다. recipe/profile이 다르면 별도 set이다.
