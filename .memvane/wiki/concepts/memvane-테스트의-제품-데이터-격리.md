## Summary
이벤트 로그는 검증된 install state root(0700, symlink 없는 경로)에만 쓴다. 테스트는 임시 HOME과 fixture state root(`realpath`로 푼 임시 디렉터리)를 사용하여 소유자의 라이브 로그에 닿지 않는다. `execFileSync`에는 `encoding:'utf8'`을 지정한다. 지정하지 않으면 Buffer 반환으로 `.trim()` 에러가 발생한다. 병렬 실행의 spurious 실패를 유발할 수 있는 `core/__pycache__`는 `.gitignore` 처리된다.
