## Summary
`QMD_SETUP_GUARD_FIXTURE=1`은 `npm test`의 테스트 전용 스위치로 `QMD_SANDBOX`와 같은 자리에서 읽힌다. runtime wake를 시작하지 않고 실제 계정 홈의 Laya embed runtime·legacy cleanup 대상을 읽거나 쓰지 않으며 운영 hook에서는 설정하지 않는다. 이벤트 로그는 검증된 install state root(0700, symlink 없는 경로)에만 쓴다. 테스트는 임시 HOME과 `realpath`로 푼 임시 fixture state root를 사용해 소유자의 라이브 로그를 피한다. `execFileSync`에는 `encoding:'utf8'`을 지정해야 Buffer 반환에 따른 `.trim()` 에러를 피한다. 병렬 실행의 spurious 실패를 막기 위해 `core/__pycache__`는 `.gitignore` 처리돼 있다.
