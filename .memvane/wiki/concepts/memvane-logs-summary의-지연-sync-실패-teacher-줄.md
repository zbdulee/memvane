## Summary
`skills/logs/SKILL.md`: summary는 각 hook action의 최신 100개 기록 duration에서 p50과 p95를 보고한다. recall에는 기록된 semantic completion fraction, latency targets, 기록된 각 stage의 p50(`recall stage p50`, `recall observation p50`과 같은 nearest-rank 값)도 보고한다. 누락된 stage는 측정되지 않은 것이며 zero-duration 결과가 아니다. event duration은 기록된 host action만 포함하며 shell startup이나 앞선 hook classification은 포함하지 않는다.
`recall observation p50`은 checkout을 관측하는 stage(`pin`, `lexical`, `stillCurrent`, `checkout`)의 median이다. checkout observation cache가 제공되면 각각 몇 ms이며, 수백 ms면 매 관측이 Git을 실행한 것이다.
`sync consecutive failed passes`는 보존된 모든 줄에서 outcome이 `failed`인 후행 `wake.sync` 줄 수와 reason, 마지막 publish pass 시각을 센다. 진행 중 pass는 세지도 끊지도 않는다. `--all`에서는 install마다 한 줄이다. 계속 증가하면 index가 publish되지 않는 것이다.
default teacher가 실행됐으면: `teacher <date>`는 해당 UTC 날짜의 per-case `learning.teacher` rows(`calls`), gold labels(`gold`, 나중에 commit된 kept answer 포함), gold로 끝나지 않은 call(`failed`, reason별), usage 합계(`usageIn`, `usageOut`, `usageCached`, `usageReasoning`)다. `teacher selected`는 gold label별 선택 카드 수(0 to 3)이며 empty selection도 유효한 label이다. `teacher models`는 각 gold label의 host와 resolved model이다.
