## Summary
Product Git commands는 replacements, grafts, lazy fetching, transport protocols를 비활성화한다. object command 전에 실제 Git executable의 no-lazy-fetch admission을 검사한다. 지원 범위는 Git 2.46+와 명시된 maintenance backports다. 이전·미확인 버전은 full repository를 검사할 수 있지만 partial repository는 `source_git_no_lazy_fetch_unsupported`로 거절한다. admission evidence를 읽지 못하면 `source_git_no_lazy_fetch_unavailable`이다. 둘 다 source-commit backoff 없는 retryable deferrals다. capture layer는 pure version predicate를 공유하며 product proof는 checkout capture를 호출하지 않는다.
지원되지 않는 Git에서는 관련 config row 전체를 검증한다. true 또는 valueless promisor, filter, partial-clone extension은 partial-clone evidence이며 뒤의 false가 이를 취소하지 않는다. malformed row도 뒤의 false로 무효화되지 않는다. false-only full repository는 허용 대상이다.
