## Summary
`docs/superpowers/plans/2026-11-09-diagnostic-logging.md`(spec `docs/superpowers/specs/2026-11-09-diagnostic-logging-design.md`)의 계획: 신규 `memvane/diagnostics/diagnostic_trace.py`가 유계 예외·경고 캡처와 조각화를 맡으며 기존 `memvane/diagnostics/event_log.py`의 install event log에 쓴다. 새 hook action·wake kind는 만들지 않는다. 인터페이스는 `diagnostic_trace.capture(decision, *, event, reason, exc=None, warning=False) -> str | None`이다. 반환 ID는 32자리 hex이며, 상세 모드 off 또는 안전 증명 실패 시 `None`이다. `capture`는 수집 전과 쓰기 직전에 동의를 확인하므로, 설정을 끄는 도중 이미 시작한 진단은 완료될 수 있으나 그 뒤 새 진단은 기록되지 않는다. 한도: 상세 최대 16 KiB, base64 조각 240자 이하·최대 96개. header는 version·ID·count·byte length·SHA-256·truncated를 갖는다. 기존 event 4096 bytes/line·4 MiB rotation·0600/no-follow·best-effort 및 host output/exit 계약을 유지한다. ID·조각은 기존 event logger와 lock·rotation을 재사용하며 exception code·host 결과에 영향을 주지 않는다. 상세 on은 예외 메시지 원문을 허용하지만 locals·별도 prompt/body 자동 수집과 외부 모델 전송은 금지한다. 검증은 `npm run test:focused -- memvane/diagnostics/tests/run.test.mjs`를 Python 3.13·3.9에서 합성값으로만 실행한다.
