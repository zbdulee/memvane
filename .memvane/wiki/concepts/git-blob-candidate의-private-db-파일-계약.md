## Summary
DB leaf directory는 현재 UID 소유 `0700`, DB는 single-link 정규 파일 `0600`이어야 한다. 경로 구성 요소의 symlink와 unsafe sidecar를 거절하고 생성은 no-clobber다. candidate v1/v2·기존 v6·알 수 없는 파일은 읽기 전용 header 확인으로 바이트 변경 없이 거절한다. 열린 handle은 DB 파일 정체성·incarnation·scope·settings policy가 바뀌면 실패한다. `BlobStore.create(path, *, project_root, repository, worktree, scope_id)`는 생성과 최초 등록, `BlobStore.open(path, *, repository, scope_id)`는 동일 repository/scope 열기, `register_worktree(project_root, worktree)`는 호환 policy의 worktree 등록을 담당한다.
