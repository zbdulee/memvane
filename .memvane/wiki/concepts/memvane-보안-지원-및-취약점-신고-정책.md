## Summary
SECURITY.md에 따라 보안 수정은 최신 `main` 릴리스 라인에 적용한다. 공개 이슈에 exploit details, credentials, private project content, tokens를 포함하지 않는다. 가능한 경우 GitHub 비공개 취약점 신고 경로 https://github.com/zbdulee/memvane/security/advisories/new 를 사용한다. 비공개 신고가 불가능하면 기술 세부사항을 공개하지 않고 GitHub에서 저장소 소유자에게 연락한다. 신고에는 영향받는 버전, host, 영향, 안전한 최소 재현, 제안하는 완화책을 포함한다. 신고 범위는 안전하지 않은 경로 처리, 의도하지 않은 색인 또는 콘텐츠 공개, hook 권한 상승, command injection, 프로젝트 또는 사용자 로컬 상태에 대한 안전하지 않은 쓰기다.
