## Summary
Git checkout capture는 자동 fetch 차단을 지원하는 Git 2.x만 사용한다. 계열별 최소 지원 버전은 2.39: 2.39.4, 2.40: 2.40.2, 2.41: 2.41.1, 2.42: 2.42.2, 2.43: 2.43.4, 2.44: 2.44.1, 2.45: 2.45.1, 2.46 이상 2.x: 2.46.0이다. 패치가 누락되거나 확인되지 않은 버전은 저장소 객체 조회 전에 `git_version_unsupported`로 거절한다. non-Git capture는 Git을 실행하지 않는다. Git 환경변수 오염을 제거하고 global/system config·선택적 index 잠금·prompt를 비활성화한다. `GIT_NO_LAZY_FETCH=1`로 누락 객체의 자동 fetch를 차단하며, 이 변수는 Git 2.39.5의 promisor 구현을 따른다.
