## Summary
`enqueue_payload`는 `run-hook` 경유 편집 hook 이벤트를 받아 LLM 호출 없이 메타데이터만 append한다. `core/wiki_compile_enqueue.py:424-477`은 이벤트 종류, `postToolUse` 설정, compile gate, queue 경로를 검사한다. `wiki_freshness.record_pending_refresh`가 None을 반환하면 enqueue하지 않는다. 통과한 이벤트는 pending refresh와 source queue에 기록되고 `request_compile` wake를 요청한다. `core/wiki_compile_enqueue.py:480-491`은 sandbox이면 즉시 0을 반환하며 비어 있거나 잘못된 JSON 입력을 무시한다. 공식 Antigravity의 자동 편집 이벤트는 이 경로로 들어오지 않는다.
