## Summary
현재 provider는 `embed_document_chunks(body, path)`를 받는다. 설계 목표 caller는 실제 경로 대신 `blobs/<blob_sha>.md`를 전달하고 이를 `blob-input-v1` input recipe에 포함한다. 동일 바이트의 이름 변경은 임베딩 입력을 바꾸지 않으며 표시 제목·filename 검색은 view membership/FTS의 실제 경로를 사용한다. 파생물은 `(blob_sha, chunk_recipe, vector_profile)` 안에서 공유한다. legacy vector는 실제 title·chunk 입력·profile이 정확히 같을 때만 재사용하며, 다르면 legacy recipe로 보존하고 새 vector를 백그라운드에서 채운다. full-text 검색은 이를 기다리지 않는다.
