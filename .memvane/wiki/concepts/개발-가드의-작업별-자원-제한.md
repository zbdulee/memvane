## Summary
`--kind test`(CI 포함), `--kind review`, `--kind hash`에는 학습용 OS 압력·CPU/RSS·headroom·swap·load 제한을 적용하지 않는다. 잠금·파일 병렬도·유한 timeout·프로세스 수와 소유 식별·정리는 적용한다. `--kind model-test`, `--kind backup`, 명시적 calibration envelope는 자원 검사를 유지하며 제품 런타임의 학습 admission도 유지한다. 실제 프로세스·모델 검증은 OS 관측이 가능한 승인된 일반 호스트에서 가드를 통해 실행한다. 샌드박스 관측 거부는 보고하며 가드를 유지한다. 진입 예시는 `npm run dev:guard -- --kind backup -- <명령>`, `npm run dev:guard -- --kind hash -- <명령>`, `npm run dev:guard -- --kind model-test -- node --test <실제 모델 시험>`이다. 계약은 `docs/runtime-resource-coordination.md`와 `docs/development-resource-safety.md`에 있다.
