## Summary
python 하한은 3.9다. 훅은 `bare python3`을 실행하며(`hooks/run-hook`) macOS의 `/usr/bin/python3`은 3.9다. PEP 604(`X | None`) annotation을 쓰는 모듈에는 `from __future__ import annotations`를 넣는다. 없으면 import 시 TypeError가 나서 훅이 exit 1로 실패한다. 시스템 python 3.9에서는 764개 중 365개가 실패했지만 3.13에서는 0개였다. `match`/`except*`는 쓰지 않는다. 시스템 python에서 남는 PyYAML 대조 테스트 실패는 환경 산물이다. macOS 3.9의 Apple libsqlite3는 `-wal`·`-shm` 없이 남은 WAL 헤더 DB를 `?mode=ro`로 열지 못한다. 따라서 `errors._query_only_uri`(`mode=rw`와 `PRAGMA query_only`)를 쓰고, `?mode=ro`를 직접 쓰지 않는다.
