## Summary
`docs/release-agent-qa.md`는 fixture 정리 후에도 증거를 보존하도록 모든 fixture 바깥에 `EVID=/tmp/qmd-release-qa-evidence-<runId>`를 mode 0700으로 둔다. 선택 경로의 hook 호출은 항상 `<install state root>/events.jsonl`에 한 줄을 남기며 모델 컨텍스트에는 넣지 않는다. 각 fresh host session 뒤 `events.jsonl`과 `.1`/`.2` 세대를 `$EVID/events-<host>-<run-session-id>.jsonl`로 복사한다. `QMD_FORCE_DEAD_PIDS`, `QMD_SETUP_GUARD_FIXTURE`, `QMD_SANDBOX` 중 하나라도 설정되면 실행은 무효다.
