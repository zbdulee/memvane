## Summary
`docs/development-resource-safety.md`의 각 실행은 `runs/ID`, checkpoint, samples, 임시 runtime root, 프로세스 트리를 따로 사용한다. 비공개 `runs/ID/samples.jsonl`에는 pressure/headroom/swap/load와 관측한 child의 CPU/RSS/start identity를 남기며 명령 인자와 환경 비밀은 제외한다. `checkpoint.json`, 단독 실행의 `active.json`, 공유 검사의 `active-test-slot-N.json`은 passed, failed, stopped, unsettled cleanup을 구분하며 로그와 checkpoint는 재부팅 후에도 남는다. 공유 검사는 unsettled `active.json`이나 자기 슬롯 기록을 거절하고 단독 실행은 모든 unsettled 기록을 거절한다. 이전 checkout은 `active.json`만 읽는다. root identity 불명, cleanup 실패, supervisor 강제 종료는 수동 검사까지 다음 실행을 차단한다. 자원 중단, 끊긴 테스트 로그, 부분 백업에는 별도 완료 증거가 필요하다. cleanup은 child 데이터·테스트 로그·부분 백업을 보존하며 운영 database나 model을 롤백하지 않는다.
