## Summary
`coordinate_release(states, *, install_both, prepare_worker)`에서 `prepare_worker(project)`는 `ready()`, `go()`, `finish()`, `close()`를 가진 객체를 반환한다. `ready()` 동안 남은 모든 project lock을 유지한다. directory와 named-lock identity를 재검사한 뒤 현재 project의 lock descriptor만 닫고 `go()`를 호출한다. 다른 project는 자기 차례까지 잠긴다. 일반 실패 시 각 worker와 자체 잔여 descriptor를 닫으며 다른 worker에 signal을 보내거나 거절을 성공으로 바꾸거나 lock file을 삭제하지 않는다. 이는 cooperative coordination이며 atomic filesystem snapshot이나 same-UID security boundary가 아니다. unlock 뒤 다른 actor가 선점할 수 있으므로 실제 selected owner와 최종 service/worker path는 별도 release gate다. 조정기 자체는 route·journal·provider policy·reader selection을 바꾸지 않는다.
