## Summary
`docs/dev/learning-state.md` M3 learning job. 저장 위치는 learning DB `learning_jobs.status`다. lock은 `learning-claim.lock`(one attempt)과 database transaction(each step)이다. 쓰는 주체는 learning cycle of the project worker이며, 모든 전이는 `learning_queue.LearningQueue`가 쓴다. 상태는 `(absent)`, `queued`, `running`, `deferred`, `staged`(종결), `blocked`이다.
전이:
- `(absent)` `plan`→`queued`
- `queued`·`deferred` `claim`→`running`
- `queued`·`running`·`deferred`: `complete`→`staged`; `consumed_elsewhere`·`fail_limit`·`source_revoked`·`unrepeatable_failure`→`blocked`
- `queued`·`running`: `defer`→`deferred`, `fail`→`deferred`
- `running` `claim_released`→`deferred`
- `blocked` `rearm`→`queued`
