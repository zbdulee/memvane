## Summary
`memvane/learning/README.md`: 학습 승인과 갱신은 host plugin 목록을 쓴다. 이 목록은 프로젝트에서 실행한 `claude|codex plugin list --json`과 Codex의 `--marketplace` 목록이다. 목록은 host·종류·프로젝트마다 기록한다(`host_inventory.py`, learning state의 `host-inventory/`, 0600). CLI 실행 파일과 host 설치 기록 파일(Codex `config.toml`과 plugin cache 디렉터리, Claude settings·plugin 기록)의 stat stamp가 같으면 CLI를 부르지 않는다. 느린 CLI를 기다리는 곳은 selector maintenance뿐이다. 기록이 없거나 stamp가 바뀐 목록은 120초 안에서 다시 받는다. 실패하면 7일 안의 기록을 쓰거나(`stale`) 해당 단계를 `host_inventory_unavailable`로 미룬다. 결과는 `learning.selector.inventory`(`refreshed`·`stale`·`unavailable`)로 남는다. 그 밖의 호출부는 기록이 없을 때만 짧은 제한으로 CLI를 부른다. 제한은 프로젝트 목록 10초, Codex marketplace 목록 2초다. setup은 시간 초과를 `deferred`·`host_inventory_unavailable`로 끝낸다.
