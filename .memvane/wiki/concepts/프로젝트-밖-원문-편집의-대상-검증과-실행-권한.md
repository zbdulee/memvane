## Summary
선택된 프로젝트 A의 편집 훅은 Claude Code·Codex·Hermes Agent의 외부 원문 변경을 선택된 프로젝트 B에 알린다. A의 검색 컨텍스트와 로컬 compile 범위는 A를 따른다. A의 기존 전체 증명과 이벤트 형식 검사를 통과한 편집만 알린다. 설치 journal에서 가장 긴 원문 root 접두사를 선택하며 동률이나 탐색 상한으로 불완전한 후보 목록은 사용하지 않는다. `verify_notification_target`은 B의 journal·route·번들·봉인된 attestation 메타데이터만 검증한다. B의 색인·claim DB를 열거나 provider·모델을 실행하지 않으며 `notificationOnly`는 작업 권한을 부여하지 않는다. 성공한 sync 뒤 B 워커의 `laya_external_edits.drain`은 discovery grant 없이 알림을 읽되 enqueue 전에 기존 전체 write 증명·현재 설정·파일 버전을 재검증한다. 증명 변경은 재시도 대상으로 남긴다.
