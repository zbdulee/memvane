## Summary
provisioning fixture는 Homebrew, npm-less candidates, explicit selection을 검증한다. partial-clone fixture는 실제 `file://` blob-filtered clones로 transport/fetch attempts와 missing objects를 계수하고 online/offline proof, dirty-source·cache rejection을 검사한다. generation fixture는 lock-release·review 경계에서 normal APIs로 G0에서 G1로 전환한다. ordinary JS dependency bytes는 다르지만 node, model, module entry, native bytes는 같다. active/bound/inactive/recovery 검사는 real proposal 직후 끝나며 journal completion·crash recovery는 별도 integration tests가 담당한다.
historical compatibility fixture는 `463e029`의 byte-preserved packaging module을 사용해 shallow CI의 history fetch를 피한다. current subbundle은 host source import path 없이 별도 `python -B -I` process에서 실행한다. unsupported-Git control은 installed Git의 no-lazy-fetch environment fence만 제거하며 historical Git binary 실행이 아니다. transport fence를 유지하고 failed fetch가 filter를 기록하면 product admission 검사 전에 config bytes/mode를 복원한다. fixtures는 temporary homes·synthetic files를 사용하며 live indexes나 model execution을 사용하지 않는다.
