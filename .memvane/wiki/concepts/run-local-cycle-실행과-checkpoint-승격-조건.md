## Summary
`docs/continual-learning.md`: `run-local-cycle`은 immutable manifest version, private revisions JSON, private trainer argv JSON, owner-only incumbent artifact를 받는다. 고정 로컬 실행 파일은 검토된 train 사례만 가진 `train` 또는 라벨 없는 validation/evaluation 사례의 `predict`를 받아 opaque artifact 하나와 bounded JSON 예측을 쓴다. parent는 wall time과 process-group RSS를 감시하고 row/file 크기를 제한하며 credential·proxy 환경변수를 제거하고 offline Hugging Face/Transformers 모드를 요청한다(OS 네트워크 sandbox는 아님). state lock은 한 cycle만 잡는다. 같은 cycle ID는 기록된 verdict를 반환하고 중단된 학습은 queued phase에서 재개한다. source revision·라벨 변경은 cycle을 거절한다. 최소 train은 검토 질문 100개, validation·독립 evaluation은 각각 최소 50 질문, 10 `none` 질문, 5 family. 승격은 같은 validation 질문에서 exact selection이 개선되고 necessary-card recall·`none` 성공이 떨어지지 않으며 irrelevant-card 주입이 늘지 않아야 한다. evaluation은 결정 뒤 보고만 한다. 승격은 private `active-checkpoint.json` 포인터만 원자적으로 바꾸며 `rollback-local-checkpoint`는 이전 포인터를 복원하고 weight는 지우지 않는다.
