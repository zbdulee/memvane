## Summary
`docs/dev/contexts/working-rules.md` 기준 python 하한은 3.9다. 훅은 `bare python3`을 실행하고(`hooks/run-hook`), macOS는 `/usr/bin/python3`으로 3.9를 탑재한다. 새 Python 모듈에 PEP 604(`X | None`) annotation을 쓰면 `from __future__ import annotations`를 함께 넣는다. 없으면 import 시 TypeError가 나서 훅이 exit 1로 끝나고 플러그인이 무동작한다. 시스템 python 3.9에서는 764개 중 365개가 실패했고 3.13에서는 0 실패였다. 이 클래스를 잡는 전용 테스트는 없으므로 리뷰에서 확인한다. `match`/`except*` 같은 3.10+ 전용 구문도 쓰지 않는다. 시스템 python으로 `npm test`를 돌릴 때 남는 PyYAML 대조 테스트 실패는 환경 산물이다. macOS 시스템 python 3.9의 Apple libsqlite3는 `-wal`·`-shm` 없이 남은 WAL 헤더 DB를 `?mode=ro`로 열지 못한다. 그래서 읽기 전용 열기는 `errors._query_only_uri`를 쓴다. 이 함수는 darwin + 3.9에서 `mode=rw`와 `PRAGMA query_only`를 사용한다. 새 읽기 경로에 `?mode=ro`를 직접 쓰지 않는다.
