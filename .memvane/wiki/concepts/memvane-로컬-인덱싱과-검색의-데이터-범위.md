## Summary
`docs/privacy.md`에 따르면 MemVane은 검토된 setup 절차로 Laya Index route를 선택한 프로젝트에서만 동작한다. route가 선택되지 않은 프로젝트에서는 indexing, recall, compile, learning 작업을 하나도 하지 않는다. 온보딩된 프로젝트의 `.memvane/wiki` 카드는 설치의 private state directory에 있는 로컬 memvane-db index에 들어간다. 원본 프로젝트 파일은 카드 생성과 경로·해시 최신성 추적에만 읽으며, 본문은 인덱싱하지 않는다. 임베딩은 장비에서 로컬 임베딩 런타임(`~/.local/state/memvane/v1/embed-runtime`, Node와 node-llama-cpp, 로컬 GGUF 모델)이 계산한다. recall 질의도 이 로컬 색인에서 처리한다. 새 장비에서 런타임을 준비할 때는 명시적 승인을 받은 뒤에만 npm registry에서 패키지를 받고, 고정된(pinned) Hugging Face URL에서 모델 파일을 받는다. 별도 telemetry 서비스는 없다.
