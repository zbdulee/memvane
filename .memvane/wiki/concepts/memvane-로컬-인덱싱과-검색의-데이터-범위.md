## Summary
`docs/privacy.md`에 따르면 MemVane은 검토된 setup 절차로 선택된 Laya Index route에 온보딩되기 전까지 비활성이다. route가 선택되지 않은 프로젝트에서는 indexing, recall, compile, learning이 실행되지 않는다. 온보딩된 프로젝트의 `.memvane/wiki` 카드는 install의 private state directory에 있는 로컬 memvane-db index에 들어간다. 원본 프로젝트 파일은 wiki 카드 생성과 path·hash freshness 추적에 쓰이며, 원본 본문은 인덱싱하지 않는다. 임베딩은 로컬 embedding runtime(`~/.local/state/memvane/v1/embed-runtime`, Node, node-llama-cpp, 로컬 GGUF 모델)이 계산하고, recall 질의는 로컬 index에서 응답한다. 새 장비에서 embedding runtime을 준비할 때는 명시적 승인 후에만 npm registry에서 패키지를, 고정된(pinned) Hugging Face URL에서 모델 파일을 내려받는다. 플러그인은 별도 telemetry 서비스를 제공하지 않는다.
