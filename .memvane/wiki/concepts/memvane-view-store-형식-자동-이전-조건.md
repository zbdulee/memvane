## Summary
선택된 main checkout은 selected sync 완료 후 off-hook worker로 `shadow-candidate*.sqlite`와 `shadow-migration-*.json`을 install state directory에 만들고 bounded steps로 새 view-store copy를 검증한다. 검증 중 recall은 이전 형식을 읽는다. 전환은 이후 sync pass의 journal update로 수행한다. 조건은 같은 selected index reader를 유지하며 Claude Code와 Codex가 각각 해당 plugin release로 프로젝트 prompt에 응답함, 각 host 응답의 유효기간 up to 24 hours, 계정에 Hermes plugin 없음, 프로젝트 폴더가 `.memvane`, bundle upgrade·state move·project folder move가 진행·중단 상태가 아님, running bundle과 selected bundle 일치다. 조건 미충족 시 검증된 copy는 대기한다. linked worktree·bundle-upgrade fence·bundle mismatch·분리된 `.memvane`/`.auto-context` checkout·QMD-origin state root에서는 이전을 시작하거나 진행하지 않는다.
