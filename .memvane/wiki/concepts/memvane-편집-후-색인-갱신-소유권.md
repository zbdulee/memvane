## Summary
플러그인은 원격 변경을 받는 Git 명령을 실행하지 않는다. 사용자의 `git pull`·checkout·편집 뒤 SessionStart(`update-queued`), PostToolUse 편집(`index`), Claude의 성공한 Bash(`file-change-event`)가 `laya-sync` wake를 기록한다. `index`는 프로젝트 안 경로만 대상으로 하며 밖 경로는 해당 프로젝트의 full-scan sync가 처리한다. off-hook owner(`core/laya_product_sync_worker.py`)는 자원 승인 뒤 bound 원문 전체를 스캔해 생성·수정·삭제·이름 변경을 반영한 full-membership generation을 게시한다. 실패·유예 시 wake를 유지하고 dispatcher가 재시도한다. hook 호출은 즉시 검색 가능성을 보장하지 않는다.
