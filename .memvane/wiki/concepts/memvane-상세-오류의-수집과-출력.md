## Summary
`skills/logs/SKILL.md`: 상세 진단은 프로젝트 settings에 `diagnostics.enabled: true`(기본 off, JSON boolean `true`만)일 때만 기록된다. 끄면 새 capture는 멈추지만 기존 것은 지우지 않는다. 모든 실패 경로가 detail을 기록하지는 않으므로 diagnostic 부재가 실패 없음을 뜻하지 않는다. 종류: `exception`(exception message 포함 Python traceback), `origin_stack`(exception 없이 warning을 감지한 caller stack), `child_stderr_tail`(child process stderr의 마지막 4096 bytes만, 앞부분이 잘릴 수 있음), `incomplete`(일부가 rotate되었거나 누락·hash check 실패; 그렇다고 말하고 누락 텍스트를 추측하지 않는다). `--details` 없이는 text와 `--json` 모두 header의 `diagnostic=<id>`와 고정 metadata만 보이고 raw parts와 옛 `prompt.text`는 숨긴다. `--details`면 raw text를 terminal-escaped로 출력한다.
