## Summary
연결 worktree에서는 recall만 동작하며 compile·수명 주기(퇴역·재생성)·dedup scan은 main checkout에서만 실행된다. `core/wiki_lifecycle.py`의 `facts["linked"]` skip이 적용된다. schema3 linked route는 sync wake를 남기지만 compile pass를 실행하지 않는다. worktree에서 수정한 원문은 브랜치가 main에 merge되고 main checkout에서 수명 주기가 실행되어야 카드에 반영된다. worktree별 compile·수명 주기 구현은 PR10 이후 설계 문서와 리뷰를 먼저 거친다.
