## Summary
`docs/project-registry.md`에서 `external_edits`는 backfill이 완료된 정상 레지스트리의 `active` main 행에 기록된 state root만 증명한다. state root가 HOME state base 바로 아래에 있고 그 이름·journal project root·route install ID가 행과 일치해야 후보다. backfill이 미완료면 기존 유계 열거를 사용한다. 두 경로 모두 레지스트리의 tombstone·`conflict`·비활성 main 행을 후보에서 제외한다. 레지스트리 부재·손상·busy·미지원 schema·안전하지 않은 경로에서는 라우팅을 중단한다.
