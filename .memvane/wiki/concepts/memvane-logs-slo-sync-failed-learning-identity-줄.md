## Summary
`skills/logs/SKILL.md`의 `--slo` 줄:
- `sync`: 후행 failed passes와, sync request부터 그 이후 시작해 publish한 첫 pass 종료까지 시간. 그런 pass가 아직 없으면 `unanswered`. request는 sync를 queue한 hook row(`reason` `sync_requested`)이며 프로젝트 밖 편집이나 성공하지 않은 편집은 queue하지 않는다. `reofferRun`은 같은 wake를 다시 요청한 최신 연속 pass 수(vector fill, linked views, vector arena에 남은 작업), `reofferRunMax`는 window 내 최장 run이다. 계속 커지기만 하는 run은 끝나지 않는 pass다. `linkedWaiting`은 linked worktree views를 대기로 남긴 published pass 수, `linkedReasons`는 reason별 대기 view 합(views × passes)이며 둘 다 줄 status를 바꾸지 않는다. `linkedWaitingLast`·`linkedHeldLast`는 최신 published pass의 waiting·held views로 지금 linked views가 대기 중인지를 보인다.
- `failed`: reason이 없는 failed 또는 refused rows.
- `learning`: window 내 stored cases, teacher answers, cycle outcomes, cycle이 언제부터 미뤄졌는지, reason 없는 cycle rows.
- `identity`: install route에 기록된 device number가 현재 값인지. 일부 restart 후 바뀌는 것은 예상되며 표시만 하고 판정하지 않는다.
