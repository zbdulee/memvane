## Summary
온보딩된 프로젝트의 git worktree는 그 worktree의 위키 카드로 만든 자기 색인을 검색하며, 이 색인은 main checkout의 백그라운드 동기화가 채운다. 처음 연 worktree나 브랜치 전환 직후에는 동기화가 끝날 때까지 검색 결과가 붙지 않는다. 위키 생성은 main checkout에서만 한다. 온보딩 후 프로젝트 `.gitignore`에 `.memvane/route.json`, `.memvane/selection.json`, `.memvane/wiki/.memvane-root` 세 줄을 추가해야 하며 플러그인은 이 파일을 수정하지 않는다. `.memvane/wiki/.memvane-root`가 추적되지 않아야 브랜치 전환 시 위키 폴더가 유지된다. 프로젝트 폴더를 옮긴 경우 이전 설치 복원은 원래 위치로 되돌린 뒤 restore를 요청하고, 이동 위치에서 바로 재온보딩하려면 `.memvane/route.json`과 `.memvane/selection.json`을 삭제한 뒤 setup을 요청한다(이전 state는 남는다).
