## Summary
`memvane/host/README.md`: main checkout 세션이 같은 저장소의 연결 worktree 파일을 편집하면 main 프로젝트의 편집이다(`edit_checkout`). 편집 경로의 가장 가까운 `.git`을 stat으로 찾고, worktree 모양의 `.git` 파일일 때만 그 worktree root를 `select_route`로 분류한다. 결과가 `worktree`이고 main route 정체성이 세션 route와 같아야 받는다. git은 checkout당 `rev-parse` 2회이며 일반 checkout 편집에서는 실행하지 않는다. 증명은 길이·throttle 검사보다 먼저 돌며 상한은 1초다.
검색과 후보 pool은 main view, 경로 규칙과 상대 경로는 worktree root 기준이며 worktree settings의 `skipPaths`를 main의 것에 더한다. main 경로가 하나라도 있으면 main 경로만, 없으면 증명된 worktree 한 곳의 경로만 쓴다. 두 곳이면 `skip_mixed_checkout`, 증명 실패는 `skip_outside_project`, 시간 초과는 `skip_checkout_proof_timeout`이다. 저장소 밖 폴더는 받지 않는다.
연결 worktree를 cwd로 연 세션의 편집 recall은 자기 view로 검색하고, pool 카드가 전부 main 게시 head와 같을 때만 main 사례가 된다(다르면 `edit_view_diverged`). main root 안의 별도 clone·submodule은 main 경로로 다룬다. 자기 인용 제외는 상대 경로 일치로 판정한다. `posttool` 행은 `editTarget`(`main`·`linked`·`linked_unproved`·`mixed`·`outside`)과 git 실행 시 `checkoutProofMs`를 남긴다.
