## Summary
`tests/structure/README.md`의 G1(엄격): 다른 도메인 `api.py`·`types.py`에서 `_` 이름을 import하거나, 그 api에서 얻은 모듈·객체·호출 결과의 `_` 속성에 접근하거나, `__getattr__` 프록시 객체와 api에 정의되지 않은 이름(모듈 `__getattr__` 전달)을 쓰는 곳을 잡는다. 연결·lock을 쥔 핸들을 돌려주는 api 함수(`_HANDLE_SOURCES`: `store.api.open_store`, `journal.api.pin_schema3`의 첫 값, journal writer scope, runtime·provider 핸들)의 결과는 소유 도메인 `types.py`의 `typing.Protocol`(`store.types.ViewStoreHandle`, `journal.types.WriterHandle` 등)에 선언된 공개 멤버만 쓸 수 있고, 그 밖은 `undeclared_handle_member`다. Protocol 메서드 서명은 구현 클래스(`_HANDLE_CLASSES`) 메서드와 같아야 한다(`handle_signature`). 값 객체를 돌려주는 api 함수(`_VALUE_SOURCES`: `journal.api.resolve_endpoint`·`reader_selection`, `recall.api.query_endpoint`)의 결과는 소유 도메인 `types.py`의 dataclass·`__slots__` 클래스에 선언된 필드와 메서드만 읽을 수 있고, 그 밖은 `undeclared_value_member`다. 추적 범위는 한 scope 안의 대입·호출·첨자·`with`·`for`, 선언된 핸들·값 타입으로 주석을 단 매개변수, 같은 모듈 최상위 함수에 위치 인자(`*args` 앞)나 키워드 인자로 넘긴 매개변수다. 메서드·중첩 함수·다른 모듈로 넘기거나 반환한 값은 따라가지 않는다.
