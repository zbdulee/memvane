## Summary
`docs/out-of-project-edit-routing.md`에서 B의 owner는 현재 blob이 알림과 일치하는 원문만 B의 편집 이벤트 compile 정책으로 처리한다. 크기 제한을 넘거나 읽을 수 없어진 원문의 알림은 폐기하고 다른 알림과 기존 discovery는 계속 처리한다. route·write 증명 실패는 재시도 대상으로 보존한다. 읽기 상한은 파일당 4 MiB이며 읽기 전후의 파일·fd 정체성과 수정 시각을 대조한다. 기존 revision-key 중복 억제·enqueue 상한·`laya-compile` wake를 재사용하고 편집 호스트를 compile 행에 보존한다. 삭제는 기존 위키 수명 주기에 요청하며 원문 소실 판정과 카드 퇴역에는 기존 Git 계보·대량 삭제 가드가 적용된다.
