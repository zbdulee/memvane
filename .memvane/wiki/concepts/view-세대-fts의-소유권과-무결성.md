## Summary
`core/laya_view_fts.py`는 세대별 FTS 구조·내용 검증을 소유한다. `ConnectionGuard(db).building(ordinal)`은 FTS sync까지 단일 commit/rollback scope를 소유하며 중첩하지 않는다. 모든 candidate rw connection은 첫 SQL 전에 `cached_statements=0`으로 authorizer를 설치한다. shadow triggers는 사용하지 않는다. schema2 fixed tables는 exact manifest를 유지하고 dynamic FTS+shadows는 등록 ordinal의 정확한 schema만 허용한다. Prepared/published FTS와 shadows는 수정할 수 없으며 verifier가 ordinal 소유권·DDL·shadow·내용의 일대일 대응과 rows/digest를 검증한다. API 외 SQL은 지원하지 않지만 손상은 read/seal verifier가 거절한다.
