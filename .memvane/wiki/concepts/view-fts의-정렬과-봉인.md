## Summary
view별 head FTS5는 `porter unicode61`과 공통 CJK spacing helper를 사용한다. BM25 path/title/body 가중치는 `1.5/4.0/1.0`이며 동점은 binary path 오름차순이다. FTS title과 결과의 `display_title`은 owner가 실제 경로·카드에서 정한 manifest의 `display_title`을 쓴다. 고정 schema manifest와 head FTS DDL·shadow 구성을 검사하고 FTS `integrity-check` 후 logical rows와 opaque physical shadow commitment를 봉인한다. 쓰기 연결은 SQL statement cache 없이 범위를 제한한 authorizer를 쓴다. FTS 변경 capability는 같은 connection·view·thread의 head 게시와 commit 중 FTS sync에 유효하다. shadow 직접 쓰기와 shadow trigger는 지원 범위 밖이며 reader는 physical commitment를 가상 테이블 조회 전에 확인한다.
