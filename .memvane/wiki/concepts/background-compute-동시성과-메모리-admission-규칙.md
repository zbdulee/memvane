## Summary
`docs/runtime-resource-coordination.md`:

background compute:
- 공유 경계의 background compute 동시성은 최대 1이다.
- CPU load가 설정된 load threshold의 75%를 넘으면 training microbatch를 1로 줄인다.
- 검증되지 않은 batch shape는 1로 유지한다.

메모리 admission:
- 추가 task memory와 명시적 system reserve를 요구한다.
- 무조건적인 35% admission floor나 40% recovery floor는 없다. 35%는 할당 후 확장의 soft 목표다.
- 기존 peak 추정치와 측정된 owned resident credit은 memory policy가 관리하며, wake queue는 model peak를 다시 예약하거나 더하지 않는다.

관측:
- system 관측에는 다른 프로젝트·세션·사용자 workload가 포함되지만, 이를 스캔하거나 종료하지 않는다.
- OS report는 macOS pressure level과 `memory_pressure -Q`, total/available memory, system load를 쓴다. Linux는 PSI 의미를 유지한다.
- 거부되었거나 알 수 없는 관측은 작업을 미룬다. foreground inference는 더 낮은 floor를 쓰고, CPU load가 높으면 batch를 줄인다.

legacy adapter:
- `LocalTrainer.call`은 legacy adapter 호출을 shared compute lease로 admit한다.
- 이미 조정된 v2 adapter는 기존 per-group TrainingGuard를 사용해 재귀 획득을 피한다.
- legacy child는 operation lease를 상속한다.
- Zero-RSS process-group 행은 live memory sample이 아니다.
