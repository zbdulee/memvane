## Summary
`skills/setup/SKILL.md`: 중단된 온보딩 단계는 같은 단계를 다시 실행하면 수렴한다. raw tree가 sync scan 한도(4,096 files 또는 64 MB)를 넘으면 prepare에서 `raw_scan_limit_exceeded`로 거절되며 build 시작 전에 보고한다. 활성화가 `initial_build_out_of_date` 또는 `initial_build_head_changed`로 거절되면 finalize를 다시 실행한다: build pass를 하나 더 요청(`initial_build_pending`)하고 build가 다시 ready가 되면 install을 reseal해 활성화를 진행할 수 있다. 활성화 전 restore는 준비된 install을 abandon해 새 install id로 새 prepare를 시작할 수 있게 하고, 활성화 후에는 selected write 이후라도 selection을 철회(`released`)해 다시 온보딩할 수 있게 한다. SessionStart가 이 plugin이 프로젝트 install record를 읽을 수 없다고(lower 또는 unknown major의 project pointer) 보고하면 restore는 state root를 읽지 않고 해당 pointer를 release하며 새 plan으로 온보딩을 시작한다. newer major pointer는 release하지 않는다. restore는 이전 install 디렉터리나 database를 삭제하지 않는다. build rescan은 selected된 적 없는 install용이며 selected 프로젝트는 `update`로 갱신한다.
