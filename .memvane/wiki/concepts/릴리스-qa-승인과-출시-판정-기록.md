## Summary
`docs/release.md`는 모든 버전 릴리스에 최종 설치 후보의 실제 신규 Claude Code·Codex 세션에서 `release-agent-qa.md` gate 실행을 요구한다. `templates/release-agent-qa-run.md`에 기록하며 모든 필수 matrix cell의 모든 필수 scenario가 `PASS`여야 한다. `FAIL`, `BLOCKED`, `NOT RUN`은 정식 릴리스를 차단한다. 버전은 모든 host manifest·marketplace entry와 일치하고 JSON manifests는 파싱되어야 한다. 릴리스 commit의 `npm test`·`git diff --check`는 L0 사전 조건이며 설치 후보 gate를 대체하지 않는다. GitHub Release에는 호환성·사용자 변경·업그레이드·알려진 제약과 미검증 OS·host를 명시한다.
