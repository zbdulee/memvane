## Summary
`LocalTrainer.call`은 legacy explicit adapter 호출에 공유 compute lease를 적용한다. 이미 자원을 조정하는 v2 adapters는 기존 per-group TrainingGuard를 사용해 outer lease의 재귀 획득을 피한다. Legacy adapter의 자식 프로세스는 operation lease를 상속하며, 부모가 종료해도 자식이 실행 중이면 compute lease가 유지된다. Zero-RSS process-group 행은 유효한 메모리 표본에서 제외한다. 종료한 자식은 원래 exit result를 유지하고, 유효한 RSS를 얻을 수 없는 실행 중 자식은 필수 resource monitor를 충족하지 못한다. 누락된 관측은 unknown으로 처리한다.
