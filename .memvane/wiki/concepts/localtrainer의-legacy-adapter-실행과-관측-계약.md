## Summary
`LocalTrainer.call`은 old explicit adapter 호출에 공유 compute lease를 적용한다. 이미 조정되는 v2 adapters는 기존 per-group TrainingGuard를 사용해 outer lease의 재귀 획득을 피한다. Legacy adapter children은 operation lease를 상속하므로 child가 실행 중이면 parent가 종료해도 compute가 해제되지 않는다. Zero-RSS process-group rows는 유효한 메모리 표본에서 제외된다. 종료한 child는 원래 exit result를 유지하고, 살아 있지만 usable RSS가 없는 child는 필수 resource monitor를 충족하지 못한다. 누락된 관측은 unknown이다.
