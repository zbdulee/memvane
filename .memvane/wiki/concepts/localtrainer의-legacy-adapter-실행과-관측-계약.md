## Summary
`LocalTrainer.call`은 old explicit adapter 호출에 공유 compute lease를 적용한다. coordinated v2 adapters는 기존 per-group TrainingGuard를 사용하므로 outer lease를 생략한다. Legacy adapter children은 operation lease를 상속하여 parent 종료만으로 compute가 해제되지 않는다. Zero-RSS process-group rows는 유효한 메모리 관측이 아니다. 종료한 child는 원래 exit result를 유지하며, 살아 있지만 usable RSS가 없는 child는 필수 resource monitor를 충족하지 못한다. 누락된 관측은 unknown이다.
