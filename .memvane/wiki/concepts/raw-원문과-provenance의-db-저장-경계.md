## Summary
Git blob·checkout view 확정 설계는 raw 원문을 디스크/Git에 두고 DB에는 경로, SHA, 브랜치, 기록 시 HEAD, 워크트리 지문만 저장한다. raw 본문·chunk·vector·FTS는 DB에 넣지 않는다. `sourceRevisions` 원문 지문은 DB가 소유하며 카드 frontmatter를 지문 저장소로 사용하지 않는다. 이는 목표 계약이다. 현재 `core/wiki_lifecycle.py`, `core/wiki_source_retire.py`, `core/git_branch_safety.py`는 frontmatter `sourceRevisions`를 근거로 사용한다.
