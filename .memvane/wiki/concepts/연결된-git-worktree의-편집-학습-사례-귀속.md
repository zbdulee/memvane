## Summary
docs/continual-learning.md에서 main checkout 세션이 같은 저장소의 linked git worktree를 편집하면 `editTarget: linked`로 main 프로젝트에 귀속한다. main view의 pool을 사용하고 capture child가 worktree의 프로젝트 루트를 해당 route로 다시 증명한 후 그곳의 파일 해시를 읽는다. 증명 실패는 `edit_checkout_unproved`, worktree 설정으로 capture가 꺼진 경우는 `disabled_in_checkout`이며, 두 checkout 중 하나라도 git ignore하는 경로는 저장하지 않는다. linked worktree에서 연 세션은 자체 view를 검색하며 그 pool의 모든 카드가 main head와 동일할 때만 main 사례로 저장한다. 불일치는 `edit_view_diverged`다. 저장소 밖 폴더는 수집 대상에서 제외한다.
