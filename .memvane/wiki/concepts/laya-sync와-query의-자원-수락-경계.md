## Summary
`product_sync_worker.py`는 임베딩 작업을 Coordinator `activity('provider', EMBED_POLICY)`로 감싸고 embed service의 모델 로드 직전에 정책을 재확인한다. `EMBED_POLICY`의 `maxRssMib` 2048, `minAvailableMib` 768, `maxLoadPerCpu` 1, `targetHeadroomFraction` 0.35는 cold-start 추정치다. query의 `embed_resident.admit_query`는 hook의 two-second provider budget 안에서 `Coordinator.check`를 수행하며 compute lease 없이 판정한다. 거부하면 `laya_query_resource_deferred`를 반환하고 로드된 모델을 유지하며 prompt를 영속화하지 않는다. Laya recall은 `runtime_work.foreground`를 호출하지 않아 background learning에 foreground demand를 표시하지 않는다.
