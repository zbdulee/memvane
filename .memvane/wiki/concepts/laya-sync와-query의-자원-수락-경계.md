## Summary
`product_sync_worker.py`는 embedding 작업을 Coordinator `activity('provider', EMBED_POLICY)`로 감싸고 embed service 모델 load 직전에 정책을 다시 검사한다. `EMBED_POLICY`는 `maxRssMib` 2048, `minAvailableMib` 768, `maxLoadPerCpu` 1, `targetHeadroomFraction` 0.35를 사용하는 보수적 cold-start 추정치다. query는 `embed_resident.admit_query`가 hook의 two-second provider budget 안에서 `Coordinator.check`를 수행하며 compute lease를 획득하지 않는다. 거부 시 `laya_query_resource_deferred`를 보고하고 로드된 모델을 유지하며 prompt는 영속화하지 않는다. Laya recall은 `runtime_work.foreground`를 호출하지 않으므로 background learning에 foreground demand를 알리지 않는다.
