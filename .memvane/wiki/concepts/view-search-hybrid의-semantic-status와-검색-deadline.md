## Summary
`search_hybrid(pin, fts_query, query_vector, limit, *, profile_id=None, max_float_work=4000000, deadline_seconds=2, path_prefixes=None, excluded_paths=None)`는 같은 pin의 `{lexical, semantic, semantic_status}`를 반환하며 순위 융합은 없다. `profile_id=None`이면 pin에 봉인된 profile을 쓴다. `query_vector=None`이면 빈 semantic과 `provider_absent`, lexical-only 세대면 `lexical_only`, 성공은 `complete`, work 예산 초과는 `deferred_work_budget`, semantic 시간 초과는 `deferred_deadline`이며 lexical 결과는 유지한다. 잘못된 profile·query·pin, seal/set 손상, checkout 변경은 defer로 숨기지 않고 거절한다. 검색 deadline은 기본 2초, `0 < seconds <= 30`이며 hybrid는 전체에 하나의 예산을 적용한다. lexical 완료 전 소진되면 결과 없이 거절한다. recall의 semantic 단계는 최대 1초다. 결과는 `path, blob_sha, body, display_title, score, view_id, gen_id`와 `evidence: "commitment-only"`, `owner_verified: false`, `snapshot_state`를 포함한다.
