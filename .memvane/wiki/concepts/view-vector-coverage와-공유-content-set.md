## Summary
`vector_spec=None`은 `lexical-only`이며 vector 참조 행·`vector_member_count`는 0이다. 명시 spec은 정확히 `{recipe_id, profile_id}`이고 `exact-complete`다. 모든 eligible member에 같은 recipe/profile의 완전한 chunk·embedding set이 필요하며 partial coverage·혼합 profile은 게시하지 않는다. `member_vectors`는 세대별 path·blob·recipe·profile과 `chunk_count`, `chunk_digest`, `embedding_digest`를 참조하며 vector 바이트를 복사하지 않는다. manifest의 전체 coverage와 실제 행을 비교하고 정렬한 참조·모드·spec의 `vectors_digest`와 참조 수를 binding root·seal에 포함한다. view 간 동일 content set은 재사용하지만 자격·provenance는 view별이다. shared set 추가로 기존 lexical 세대·pin은 변하지 않으며 새 세대와 같은-view head CAS가 필요하다.
