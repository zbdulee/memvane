## Summary
`npx skills add`의 skills CLI는 skill 디렉터리와 링크만 관리한다. runtime·모델·DB에는 외부 영구 경로와 installer 소유의 update/remove 수명주기가 필요하다. skill 복사만으로는 Codex 번들 hook 등록이나 runtime postinstall·migration·uninstall이 생기지 않는다. 공통 installer를 재사용하는 가벼운 `npx skills add` 설치 진입점은 검토 대상이며 구현과 배포는 보류 상태다. Claude/Codex adapter와 공식 hook trust는 별도 검토 대상이다.
