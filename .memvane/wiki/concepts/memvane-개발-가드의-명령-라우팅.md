## Summary
`docs/development-resource-safety.md`의 `npm test`와 `npm run test:focused -- memvane/DOMAIN/tests/run.test.mjs` 또는 `tests/PATH.test.mjs`는 `scripts/development_guard.py`를 거친다. wrapper는 셸 명령을 조립하지 않고 argv를 직접 실행하며, `node --test --test-concurrency=1`을 강제하고 QMD fixture/log 격리를 유지한다. 백업은 `npm run dev:guard -- --kind backup -- COMMAND ...`, 해시 작업은 `--kind hash`를 사용한다.
`npm test`는 `--exclusive`로 `test:part1`(sync, registry, host), `test:part2`(journal, store, learning, recall), `test:part3`(나머지)를 실행하며 각 part의 예산은 1,800초다. focused 검사는 기본 900초이며 sync와 registry runner는 각각 실행한다. CI는 Node 버전마다 `npm run test:partN`을 세 job으로 실행한다.
직접 실행한 셸 명령과 이전 checkout은 자동으로 가로채지 않으므로 agent가 wrapper를 사용한다. `npm run test:guard-unit`은 실제 host probe와 모델 작업이 없는 소규모 Python 안전 검사에만 적용하는 bootstrap 예외다.
