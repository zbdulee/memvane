## Summary
`laya_active_upgrade`는 선택된 번들을 교체하는 동안 selection ledger를 `upgrading`으로 유지한다. 복구는 원래 backup, build record, store counts, generation, vector profile, project scope와 collection paths를 보존한다. 쓰기 전에 journal의 project device/inode와 현재 settings-derived collections가 일치해야 한다. 각 intent·metadata write, journal CAS, activation, fence release 직전에 project identity와 settings-derived scope를 다시 검사한다. Settings, project identity, metadata, journal evidence, counts 또는 write-history가 바뀌면 복구를 거절한다.
