## Summary
`setup` skill은 MemVane 색인 온보딩을 minimal settings → `plan-fresh-wiki-origin` → `review-index-provider` → `prepare-fresh-wiki-origin` → `finalize-index-origin` → `activate-index-origin` 순으로 수행한다. 되돌리기는 `restore-index-origin`으로, 활성화 전에는 abandon, 활성화 뒤에는 선택 해제와 이전 설치 보존이다. Laya embed runtime 준비·GC와 명시적 학습 프로필도 담당한다. 모든 동작은 `memvane/app/setup_entry.py`로 하고 적용은 명시 요청 시에만 한다. SessionStart 온보딩 안내가 가리키는 skill이다.
