## Summary
`skills/setup/SKILL.md` 온보딩 후반 단계:
4. `index-build-status`는 build `phase`와 최신 bounded progress snapshot(stage, ingested cards, processed vector content sets)을 보고한다. 최근 snapshot이 없으면 count가 `null`일 수 있으며 0으로 추론하지 않는다. `ready`를 기다린 뒤 finalize와 activate를 한다. ready는 활성화 후 lexical search가 가능하다는 뜻이며 vector filling은 백그라운드에서 계속된다. `index-origin-status`는 install record를 보여준다.
5. `finalize-index-origin`은 `initial_build_finalized`, 또는 build pass가 더 필요하면 `initial_build_pending`을 반환한다.
6. `activate-index-origin --approve-index-origin-activation`은 프로젝트의 index를 선택하고 `selected`를 반환한다. 사용자의 명시적 활성화 요청 시에만 실행한다. 활성화는 이 프로젝트의 자동 학습(로컬 training·evaluation, default teacher의 gold labeling)도 승인한다. training과 evaluation은 이 머신에 머문다. labeling 시 각 captured case의 edit text와 candidate cards 본문이 그 case를 만든 세션의 host CLI(Claude Code 또는 Codex, 같은 account·provider)로 간다. git ignore 파일과 `skipPaths`는 capture에서 제외된다. teacher를 끌 수 있다고 알린다. `recover-index-origin`은 중단된 활성화를 재개한다.
7. `restore-index-origin --approve-index-origin-restore`는 `restored`(abandoned 또는 withdrawn) 또는 `released`를 반환하며 명시적 요청 시에만 실행한다. `index-build-rescan`은 한 번도 selected되지 않은 install에 build pass를 다시 요청한다.
