## Summary
`docs/dev/learning-state.md` M5 evaluation(문서 일부만 확인). 저장 위치는 learning DB `learning_evaluations.status`다. lock은 `evaluation-claim.lock`(one attempt)과 database transaction(each step)이다. 쓰는 주체는 learning cycle of the project worker다. 상태는 `(absent)`, `queued`, `running`, `deferred`, `waiting_quality`, `completed`, `blocked`(종결)이다.
확인된 전이(별도 표기 외 `evaluation_queue.EvaluationQueue`):
- `(absent)` `ensure`→`queued`, `reject`→`blocked`
- `queued`·`deferred` `claim`→`running`
- `queued`·`running`·`deferred`: `block`·`fail_limit`·`reject`→`blocked`; `evaluated`→`completed`; `too_few_cases`→`waiting_quality`; `carried`→`(absent)` (`candidate_close.carry_candidate`)
- `queued`·`running` `defer`→`deferred`
- `running` `claim_released`→`deferred`
`waiting_quality` 이후 전이는 원문 잘림으로 확인되지 않았다.
