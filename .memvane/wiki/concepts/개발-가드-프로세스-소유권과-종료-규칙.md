## Summary
`docs/development-resource-safety.md`의 child는 자체 session으로 시작한다. monitor는 검증된 process group과 관측한 모든 descendant를 추적하며, 다른 group을 만들거나 reparent된 descendant도 포함한다. 원래 group의 마지막 검증된 anchor가 사라지면 해당 숫자 PGID는 이후 추적에 편입하지 않는다. 각 PID는 관측한 start time과 결속하며 start time이 다른 재사용 PID는 제외한다. signal마다 identity를 다시 읽고 검증된 소유 PID에만 TERM을 보낸 뒤, 살아 있으면 KILL을 보낸다. 사용자 application, process name, 미검증 process group, 기존 session은 종료 근거가 될 수 없다.
