## Summary
child는 별도 session에서 시작한다. monitor는 검증된 process group과 관측된 모든 descendants를 추적하며 새 group 생성·reparent 이후도 포함한다. 마지막 검증된 original-group anchor가 사라지면 해당 숫자 PGID는 재채택하지 않는다. PID는 관측 start time에 결합하며 시작 시간이 다른 재사용 PID는 제외한다. 매 signal 직전에 identity를 다시 읽고 검증된 owned PID에만 TERM, 살아 있으면 KILL을 보낸다. 사용자 application·process name·미검증 process group·기존 session을 종료하지 않는다. 기존 사용자 session과 automation 중단에는 별도 승인이 필요하다.
