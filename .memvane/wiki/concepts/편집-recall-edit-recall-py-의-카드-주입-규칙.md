## Summary
`memvane/host/README.md`: `edit_recall.py`는 `posttool`의 편집 recall 꼬리다. 편집 증명과 route proof 재확인이 끝난 뒤, 편집이 추가한 텍스트로 선택된 view를 검색한다. 세션에서 아직 주지 않은 카드를 최대 2장 Claude·Codex PostToolUse `additionalContext`로 준다. 본문은 600토큰이며, selector가 답하지 못하면 기본 순위 1장을 준다. hook 진입부터 10초 안에 끝난다. 예외·proof 변화·예산 초과 시에는 `{}`·exit 0으로 응답하고 sync·provider wake를 남기지 않는다. 세션 상태(이미 준 카드, 편집 recall 시각)는 install state root의 `edit-recall-sessions/`에 non-blocking flock으로 둔다. 이벤트는 `recall.edit` 한 줄이다. main checkout은 응답 뒤 `learning-capture` 자식에 후보 pool을 넘긴다. 끄는 스위치는 `MEMVANE_EDIT_RECALL=off`다. capture는 기존 CPU share를 확보한 경우에만 supervisor를 시작하고, share FD는 supervisor와 worker가 종료할 때까지 유지한다. 프롬프트 recall은 학습 사례를 수집하지 않는다.
