Codex inventory 조회는 2초 또는 호출자 잔여 deadline 중 짧은 쪽으로 제한하며, 만료되었거나 1초 미만이면 inventory 없이 `timeout`을 반환한다. 여러 scope의 동일 Claude binding은 허용, 충돌·이상 기록은 거절한다. inventory는 provider API key나 모델 세션 없이 기존 plugin inventory 명령만 호출한다. 이 검사는 새 model/runtime 승인이나 실패한 attestation 우회가 아니며, live 실행 주장 전 별도 bounded synthetic inference 검사가 필요하다.
