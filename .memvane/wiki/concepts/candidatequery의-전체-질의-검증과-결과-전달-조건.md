## Summary
`CandidateQuery`는 catalog를 열지 않고 explicit binding을 사용한다. 기본 한도는 `max_file_bytes=1_000_000`, `max_query_bytes=5_000_000`, `max_query_files=200`이며 `search_candidates_verified`의 `refill_factor=4`다. 시작 시 binding·seal scope/generation/manifest·incarnation과 canonical no-follow root의 `(dev, ino)`를 검증한다. root 오류는 `collection root unavailable`·`collection root replaced`다. exclusions는 한 번 읽으며 `finish()`에서 seal의 `rev_epoch`·incarnation·root identity를 재검사한다. 실패는 `index_stale`로 전체 결과를 무효화한다. scope·generation·collection 위반, malformed row, `fetch` 오류는 `candidates_unverified`가 아닌 `index_stale`이며 session을 poison한다. 이후 `finish()`는 `candidate query already failed`를 발생시킨다. 결과는 `finish()` 성공 후에만 전달한다.
