## Summary
`memvane/learning/README.md`: 기본 namespace의 adapter 경로만 달라진 정책은 heal의 내용·승인 범위 검증으로 재결속한다. 미활성 기본 namespace는 profile을 만들기 전에 현재 번들의 adapter 경로로 원자적으로 고정한다. interpreter·model·다른 정책 키가 달라지면 거절한다. 정책 다이제스트가 달라지면 추론 증명을 재준비한다. 이미 승인된 profile은 이 경로로 재기록하지 않는다. 선택 설치의 기본 자동 학습 profile은 별도 renewal 경계에서 공식 번들 업데이트의 코드·설치·adapter 경로와 파생 digest만 갱신한다. 정책의 다른 필드, interpreter·model, project·namespace, operations·cohort 전체, 기존 만료와 profile 선택은 유지한다. 수동·custom·teacher·opt-out·만료된 승인은 자동 갱신하지 않는다. settings와 최초 setup 승인 기록은 쓰지 않는다. 기본 grant는 해당 host가 프로젝트에서 선택한 MemVane marketplace와 출처·설치 바이트에 결속하며, 다른 marketplace 항목은 결속하지 않는다. renewal intent는 다섯 승인 파일의 원래/새 바이트 쌍을 기록하고 소비를 차단한다. 같은 대상은 CAS로 이어서 게시한다. 더 새 대상은 원래 승인으로 CAS 복원을 끝낸 뒤 다시 계획한다. 설명되지 않는 파일·settings 변경과 낮은 host는 fence를 유지하며 거절한다. 설치 manifest는 0644를 허용하며 소유자·경로·link·비신뢰 쓰기 권한과 읽기 전후 fd/path 정체성을 검사한다. intent와 승인 상태 파일은 별도의 소유자 전용 읽기 규칙을 유지한다.
