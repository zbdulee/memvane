## Summary
`docs/development-resource-safety.md`의 `npm test`는 `--exclusive`로 `test:part1`부터 `test:part4`까지 4개 part를 실행하며 각 예산은 1,800초다. 초기 샘플의 memory pressure가 `normal`이면 파일 3개를 병렬 실행하고 그 외에는 1개씩 실행한다. 상태에는 `testConcurrencyRequested`, `testConcurrency`, `pressure`를 기록한다. CI는 `MEMVANE_TEST_CONCURRENCY=1`로 설정하고 Node 버전마다 `npm run test:partN`을 4개 job으로 나눈다. `scripts/test_part.mjs <k>/<n>`은 `tests/support/durations.json`의 기록에 따라 오래 걸리는 Python 테스트 모듈부터 누적 시간이 가장 짧은 part에 배정한다. 마지막 part는 나머지 node 테스트 파일도 실행한다. `node scripts/test_part.mjs --plan`은 part별 기록 시간을 초 단위로 출력하며 구조 검사는 각 part를 1,200초 이하로 유지한다.
