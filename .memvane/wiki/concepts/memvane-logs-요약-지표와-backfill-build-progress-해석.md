## Summary
`skills/logs/SKILL.md`: summary는 각 hook action의 최근 100개 기록 duration으로 p50·p95를 보고한다. recall은 추가로 기록된 semantic completion fraction, latency targets, 각 기록 stage의 median을 보고한다. 누락된 stage는 측정되지 않은 것이며 0-duration 결과가 아니다. event duration은 기록된 host action만 포함하고 shell startup이나 앞선 hook classification은 포함하지 않는다.
`wiki.backfill`: `pending`·`dispatched`는 미완료 source revision, `settled`는 compile worker가 terminal attempt(no-card 결과 포함)를 끝냄, `skipped`는 frozen revision이 바뀌거나 사라지거나 excluded됨. `settled`도 `complete`도 카드 생성·검증을 증명하지 않으므로 카드 생성과 검증은 각자의 event로 따로 보고한다.
`index.build.progress` 줄은 최근 완료 pass의 stage와 가용 ingest·vector count를 기록하는 snapshot이다. 최근 줄이 없으면 `index-build-status`는 0이 아니라 unknown count를 보고한다.
