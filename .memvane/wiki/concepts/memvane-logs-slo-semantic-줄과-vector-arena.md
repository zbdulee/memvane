## Summary
`skills/logs/SKILL.md`의 `--slo` `semantic` 줄: query vector가 있는 recall 중 semantic search가 완료된 비율, arena가 한 번이라도 응답한 뒤 vector arena에서 응답한 비율(arena가 꺼진 recall은 제외), 미완료 state별 count, 기록된 vector cache states를 보인다. `vectorCache=unmeasured`는 window의 어떤 row도 state를 기록하지 않았다는 뜻이며 0이 아니다. cache state가 `inconsistent`인 recall 하나만 있어도 recall이 20개 미만인 window에서도 줄이 `over`다. `arenaRemaining`은 sync owner의 마지막 `vector.cache` event가 arena 밖에 남긴 embedding set 수, `arenaSkipped`는 그 이벤트가 옮기지 못한 이유(`quota`, `format_newer`, `write_unavailable`, `set_unreadable`, 또는 failure code)다. `arena`는 한 recall이라도 cache state(`vectorCache`)를 보고하면 판정되며, arena가 한 번도 응답하지 않은 install은 누락값이 아니라 share 0이다. `arenaComplete`와 `arenaSemanticP50`/`P95`는 arena가 응답한 recall(query vector 하나)의 completion과 semantic stage다.
