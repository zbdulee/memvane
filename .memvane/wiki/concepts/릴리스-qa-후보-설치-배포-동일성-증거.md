## Summary
`docs/release.md`에 따라 GitHub Release 게시 후 clean QA account에서 public marketplace로 설치하고 RQA-ID-00 + core smoke로 배포본과 QA 후보의 동일성을 확인한다. 실행 기록에는 commit SHA, `artifactManifestSha256`, 설치·배포 identity, host, OS, Node, Python, embedding runtime 및 model versions, search-result proofs, blockers와 미실행·차단 점검을 보존한다. transcripts와 logs는 private evidence store에 두고 릴리스 노트에는 요약과 해시만 싣는다. 릴리스 노트에는 compatibility notes, user-visible changes, upgrade notes, known limitations와 검증하지 않은 모든 OS 또는 host도 명시한다.
