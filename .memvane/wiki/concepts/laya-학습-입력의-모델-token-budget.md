## Summary
Laya 0.3.20 adapter는 정확한 prompt와 전체 compact body를 tokenize하고 양쪽 option markers와 전체 state token IDs를 검사한다. 모델 sequence budget을 넘는 학습 사례는 거절하며 입력을 자르지 않는다. multilingual checkpoint는 tokenizer가 8192를 광고해도 `max_len=1024`를 선언하므로 모델의 1024-token budget을 사용한다. 16 KiB는 저장 상한이며 입력 수용 보장이 아니다. `laya_raw.py`는 assumed 0.3.23 candidate pin을 사용하는 별도 raw-data adapter로, 검증된 0.3.20 integration과 구별한다.
