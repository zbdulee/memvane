## Summary
`docs/privacy.md`의 Learning labels 항목을 정리한다. 온보딩된 프로젝트의 기본 learning profile은 캡처된 edit case를, 그 case를 캡처한 세션의 host CLI로 라벨링한다. Claude Code case는 `claude` CLI로, Codex case는 `codex` CLI로 보내며 두 CLI 모두 사용자 본인 계정으로 로그인된 상태다. case를 다른 host로 보내는 일은 없다. 호출 한 번에는 edit text와, case 캡처 시점에 저장한 후보 wiki 카드 최대 15개의 본문만 넘긴다. source files, card source paths, injected context는 첨부하지 않는다. git-ignored 경로나 `skipPaths` 아래의 편집은 캡처하지 않는다. host CLI와 계정 설정에 따라 CLI가 이 내용을 provider로 보낸다. CLI가 자체 기본 지침과 사용자의 global Codex instructions 파일을 모델 입력에 추가할 수도 있다. 호출은 빈 임시 작업 디렉터리에서 실행되며, 실행 전에 host CLI의 isolation 옵션을 강제한다. plugin은 CLI의 credentials를 읽거나 옮기지 않는다. `CLAUDE_CONFIG_DIR`을 리디렉션한 세션은 shared learning capture에서 제외된다. worker는 `CLAUDE_CONFIG_DIR` 없이 `claude`를 실행하므로, 모든 호출이 case를 캡처한 기본 `~/.claude` 계정에서 이루어진다. setup skill에 요청해 프로젝트의 teacher를 끄면 이 호출만 멈추고, capture, recall, local training은 계속된다.
