## Summary
`docs/privacy.md`의 Learning labels에 따르면 온보딩된 프로젝트의 기본 학습 프로필은 편집 사례를 수집한 세션의 사용자 계정과 CLI로 라벨링한다. Claude Code 사례는 `claude` CLI, Codex 사례는 `codex` CLI로만 보낸다. 호출 입력은 편집 텍스트와 수집 시 저장한 후보 wiki 카드 본문 최대 15개로 한정하며 원본 파일, 카드 원본 경로, 주입 문맥은 첨부하지 않는다. git-ignored 경로와 `skipPaths`의 편집은 수집에서 제외한다. host CLI와 계정 설정에 따라 해당 내용이 제공자에게 전송되며 CLI가 자체 기본 지침과 사용자의 전역 Codex 지침 파일을 모델 입력에 추가할 수 있다.
