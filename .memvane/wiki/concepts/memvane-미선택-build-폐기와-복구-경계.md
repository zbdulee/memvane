## Summary
결합됐지만 선택된 적 없는 build는 `retire-index-origin`과 `--approve-index-origin-retire`로 폐기한다. stores와 journal은 유지하고 자신의 project marker와 build pointer만 해제하며 다음 설치는 새 state directory와 install ID가 필요하다. 이 경로 밖의 mismatch에는 `recover-index-origin` 또는 fresh review가 필요하다. marker·pointer를 수동 삭제하거나 model·wiki·manuscript·settings·learning state를 덮어쓰거나 삭제하지 않는다.
