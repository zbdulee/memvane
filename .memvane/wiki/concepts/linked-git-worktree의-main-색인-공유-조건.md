## Summary
linked worktree에는 추적되지 않는 route record·selection marker가 자체적으로 없다. `laya_index_host_route._worktree_route`는 Git이 linked worktree로 보고하고 공통 git dir이 main checkout의 git dir이며, cwd와 worktree 루트 사이에 route record·selection marker가 없을 때 검사한다. 프로젝트 상대 경로가 같고 main 분류가 정확히 `candidate`이며 양쪽 settings의 이름·collection·경로·role·위키 경로가 같으면 `worktree` route다. `.memvane`·`.auto-context`는 동등하게 취급한다. 검색은 main의 마지막 게시 색인을 읽기 전용으로 사용한다. sync·wiki compile·wiki lifecycle·학습은 main에서만 실행하므로 worktree 전용 변경은 반영되지 않는다. 불일치 시 자기 cwd 기준 분류를 따른다.
