## Summary
추적되지 않는 route record·selection marker는 linked worktree에 자체적으로 없다. `laya_index_host_route._worktree_route`는 Git이 linked worktree로 보고하고 common git dir이 main checkout의 git dir이며 cwd와 worktree 루트 사이에 route record·selection marker가 없을 때 검사한다. 프로젝트 상대 경로가 같고 main 분류가 정확히 `candidate`이며 settings의 이름·collection·경로·role·위키 경로가 같으면 `worktree` route다. `.memvane`·`.auto-context`는 동등하게 취급한다. 조건 불일치는 자기 cwd 기준 분류를 따른다. wiki compile·wiki lifecycle·학습은 main checkout에서만 실행하며 worktree에서만 바뀐 원문은 compile 대상이 아니다. 검색 동작은 main checkout journal이 선택한 v6 reader 또는 schema3 reader에 따른다.
