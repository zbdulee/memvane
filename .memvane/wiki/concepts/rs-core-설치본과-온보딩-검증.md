## Summary
`docs/release.md`의 `RS-core`는 계정 shell에 sandbox 또는 test 변수가 있으면 실행을 무효 처리한다. 합성 프로젝트의 각 raw document에 verified card 하나를 두어 온보딩에서 wiki compile 없이 인덱싱한다. `RS-UPDATE`는 README에 따라 플러그인을 업데이트하고 프로젝트에 활성화하며 Codex hook trust는 사용자가 승인한다. `RS-ID`는 설치 파일을 release commit과 대조한다. `RS-MODELURL`은 계정에서 pinned model 주소를 받아 크기와 sha256을 검증한다. `RS-ONBOARD`는 프로젝트 온보딩과 plan 적용을 요청한다. `RS-HOSTENV`는 온보딩 뒤 양쪽 호스트의 세션을 다시 시작해 프로젝트 로그의 SessionStart row를 확인하며 해당 행이 없는 호스트의 후속 항목은 `BLOCKED`다.
