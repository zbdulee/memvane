## Summary
`docs/continual-learning.md`: 카드 선택은 선택된 Laya recall의 필수 단계이며 프로젝트 설정이 아니다. 선택된 Laya 응답 경로(`memvane/host/host_response.py`)는 증명·게시된 wiki 후보를 최대 15개 읽는다. 준비된 selector(승인된 shared trial/profile 또는 로컬 `active-checkpoint.json`)가 있으면 selector의 선택이 최종이며 0장도 포함한다. selector가 없거나 질의 시점에 답하지 못하면 검증된 후보를 hybrid rank 순으로 최대 3장 주입하고 사유를 기록한다. 로컬 Laya adapter는 각 후보의 전체 compact wiki body를 보고 0–3개 카드 ID를 반환한다. hook은 해시된 후보·선택 ID, snapshot fingerprint, fallback 사유, 관측 시간/RSS를 기록한다. 상태 누락, 잘못된 모델 출력, 바뀐 checkpoint, runtime 실패는 hybrid rank를 유지한다. `live-selector.json`과 활성 로컬 checkpoint가 각각 필요하다. 설치 패키지 byte identity, `ready` setup gate, 기존 state directory 해석은 Laya 예측 성공을 증명하지 않는다. 승인되지 않은 adapter 경로를 가진 policy는 `unsupported_adapter`로 fallback한다. 학습 capture(`context_learning.laya_learning.capture_recall`)는 hook 응답 flush 뒤에만 실행되고 예외를 내지 않으며 고정 상태만 기록한다.
