## Summary
`skills/logs/SKILL.md`: `--learning-check`는 프로젝트의 learning state를 쓰기 없이 읽고 각 consistency rule(`I-1`..`I-9`, `G-1`, `G-7`; 규칙은 `memvane/learning/context_learning/invariants.py`에 정의)을 위반하는 row 수를 출력한다. 기대값은 `0 violation(s)`이고 `no_namespace`는 해당 프로젝트에 learning이 설정되지 않았다는 뜻이다. count만 출력하며 case, job, cycle 이름은 나오지 않는다. exit code는 count나 status와 무관하게 항상 0이므로 code가 아니라 출력된 줄을 읽어야 한다. staged candidate마다 artifact를 hash하므로 해당 model files를 읽는 만큼 시간이 걸린다.
