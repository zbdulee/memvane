## Summary
`PreparedWorker`의 완료 판정은 outcome과 installation kind를 함께 검사한다. active·bound·inactive upgrade, state move, project-folder move는 각각 별도 terminal code를 사용한다. state/project move outcome은 result row의 structured field로 유지되며 bundle step만 완료되고 move가 미완료이면 release는 완료되지 않는다. unknown·malformed row와 미완료 learning upkeep는 거절한다. helper는 equal-version drain, newer identity 위조, replacement 강제용 interpreter 변경을 허용하지 않으며 실패한 owner-path gate를 `read_only_handover`로 대체하지 않는다. companion-host sealing, 정상 read/write proof, recall check, service path, cache integrity는 별도 검증한다. metadata check도 full read/write·runtime-path release gate를 대체하지 않는다.
