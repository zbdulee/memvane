## Summary
`memvane/settings/README.md`: `resolve_paths.py`는 collectionPaths를 경로로 매핑하고 risky path / allowRoots traversal을 검증한다. 출력은 세 목록이며 `entries` = `indexEntries` ⊎ `sourceEntries`다. `entries`는 설정에 적힌 전부로 compile source 경로가 쓴다. `indexEntries`는 인덱스 대상(`INDEXED_ROLES`)이다. `sourceEntries`는 role `source`이며 인덱스에서 빼야 할 항목이다. 항목 모양은 `{name, path}`를 유지한다. role을 항목에 얹으면 downstream이 role 문자열을 다시 비교하게 되어, role 판정을 한 곳에 두려는 목적에 어긋난다. traversal 판정은 `contained_path(base, path, roots)` 한 곳에서 한다. `safe_collection_path`는 base=cwd 래퍼이고, recall의 wiki `sources[].path`는 base=project_root로 같은 함수를 쓴다. `from __future__ import annotations`를 지우면 안 된다. 훅이 macOS 시스템 python 3.9로 이 모듈을 import하는데 `X | None`(PEP 604)은 3.10부터다.
