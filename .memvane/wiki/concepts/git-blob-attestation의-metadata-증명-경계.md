## Summary
`put_fingerprint(spec) -> fingerprint_id`, `fingerprint(id)`, `put_attestation(spec) -> trust_digest`, `attestation(id)`는 metadata-only fingerprint와 allowlisted versioned receipt를 다룬다. `attestation_sources`는 attestation별 순서 있는 fingerprint/span 참조를 보존한다. Source observation은 caller-owned evidence claim이며 원문 body 읽기·삭제·compilation·trust 권한을 증명하지 않는다. Locator bounds는 metadata 검사다. `legacy_unbound`는 유지하며 rebound는 같은 blob의 prior trust와 path/SHA/spans/policy가 일치하는 새 불변 commitment여야 한다. 자동 operational trust가 아니다. Generation `card_sources`는 후속 PR 범위다.
