## Summary
`docs/release.md`의 `P5 real model`은 승인된 머신에서 `npm run dev:guard -- --kind model-test -- node --test --test-concurrency=1 memvane/resident/tests/resident-model-smoke.test.mjs`를 단독 실행하고 guard run id를 기록한다. 선택된 로컬 embed runtime을 읽기 전용으로 사용하고, 일회용 runtime state에서 합성 문서와 질의를 resident의 worker 시작 경로로 보낸다. `ready`, guard refusal, guard stop은 각각 기록하며 refusal과 stop은 통과 조건을 충족하지 못한다. learning cycle 경로가 바뀌면 실모델 learning 검사도 필수다. `P5` 이후 최종 커밋이 바뀌면 새 커밋에서 다시 실행한다.
