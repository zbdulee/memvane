## Summary
`docs/dev/learning-state.md` M4 cycle. 저장 위치는 learning DB `cycles.status`다. lock은 `learning-claim.lock`(training), evaluation claim(evaluation), apply journal(apply)이다. 쓰는 주체는 learning cycle of the project worker다. 상태는 `(absent)`, `training`, `failed`, `deferred`, `staged`, `staged_evaluated`, `applied`(종결)이다.
전이(`automatic_staging._train_pinned`): `(absent)` `train_started`→`training`; `training` `train_deferred`→`deferred`, `train_failed`→`failed`, `trained`→`staged`; `failed` `train_deferred`→`deferred`, `trained`→`staged`; `deferred` `train_failed`→`failed`, `trained`→`staged`.
평가·적용: `staged` `evaluated`→`staged_evaluated` (`automatic_staging._evaluate_impl`); `staged_evaluated` `applied`→`applied` (`candidate_apply._finish_cycle`), `carried`→`staged` (`candidate_close.carry_candidate`), `reevaluation_needed`→`staged` (`automatic_staging._prepare_evaluation`).
