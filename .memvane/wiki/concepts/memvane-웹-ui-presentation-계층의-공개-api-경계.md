## Summary
`tests/structure/context-map.json`에서 `ui: 12`는 최상위 presentation 계층이다. `app: 11`과 순환 없이 `entry/run.py`와 `memvane/ui/cli.py`만 연결한다. G1 / G2에 따라 `memvane/ui/`가 import할 수 있는 범위는 하위 도메인의 공개 `api.py`·`types.py`와 `memvane/kernel/`이다. G5 필수 파일 3종은 `README.md`, `api.py`, `types.py`이며 `ui/api.py` 공개 속성은 30개 미만(목표 ≤ 10개)으로 유지한다. `types.py`는 G7에 따라 IO를 수행하지 않는다.
