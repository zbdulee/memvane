## Summary
branch key는 `refs/heads/<name>`, detached HEAD는 `detached:<oid>`다. unborn branch의 HEAD는 `None`이며, non-Git의 branch key는 `non-git`, HEAD·object format은 `None`이다. Git 손상·권한·명령 실패를 non-Git 상태로 숨기지 않는다. 같은 등록과 branch는 같은 view identity를 사용한다. 같은 branch의 HEAD가 다른 계보로 움직이면 view identity는 유지되고 checkout digest가 달라진다. linked worktree는 repository 등록을 공유할 수 있으나 worktree/view identity는 각각 가지며 index·operation evidence도 해당 worktree에 속한다. 전체 Git 관측 전후에 ref·HEAD·index·operation·경로 identity를 대조하고, 변경 시 유한 예산 안에서 재시도하거나 거절한다.
