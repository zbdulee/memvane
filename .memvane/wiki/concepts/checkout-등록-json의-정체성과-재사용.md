## Summary
Checkout 등록 JSON은 canonical 경로·dev/ino와 repository/worktree의 상호 귀속을 묶는다. 등록 API를 다시 호출하면 새 UUID를 생성하므로 같은 등록을 재사용하려면 호출자가 반환 JSON을 보관해야 한다. 모듈은 등록 JSON을 디스크나 journal에 저장하지 않는다. 같은 경로에 디렉터리를 재생성하거나 등록된 디렉터리를 옮겨도 기존 등록을 자동 인계하지 않는다. 같은 common Git dir라도 프로젝트 상대 위치가 다르면 별도 등록이며, 별도 clone과 submodule에는 부모 저장소의 등록을 적용할 수 없다. UUID와 digest는 정체성 값이며 설치·검색·쓰기 권한을 부여하지 않는다.
