## Summary
`memvane/learning/README.md`: legacy 전체 registry SHA의 이행은 고정된 공식 1.0.15 배포의 기존 code/executable/manifest/adapter 지문, 기본 승인 체인, 현재 공식 remote 출처를 모두 확인한다. 구 캐시가 있으면 저장 지문으로 다시 검증하고, 없으면 저장된 배포 지문을 사용한다. 당시 registry의 source는 전체 SHA로 복원할 수 없으므로 legacy directory/custom 출처와 다른 배포 지문은 자동 이행하지 않는다. 새 self binding은 자기 source 변경도 거절한다. 중단된 기본 등록은 기존 설치 binding을 검증한 뒤, adapter 경로 고정보다 먼저 복구한다. 복구는 backup과 source settings의 결속, 그리고 모든 복원 대상의 경로·권한·내용을 확인한 뒤 단계를 기록한다. settings가 backup과 같으면 파일을 쓰지 않는다. 다른 사용자 편집은 거절한다. 0644 settings는 허용하지만 그룹 쓰기가 가능한 0664와 symlink·hardlink는 거절한다. 복구가 중단된 뒤 재진입하면 검증된 backup 내용으로 이미 복원된 namespace 파일도 허용한다.
