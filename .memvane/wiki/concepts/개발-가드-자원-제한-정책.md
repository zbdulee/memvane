## Summary
35% available-memory 제안은 보수적이며 미보정이다. 24 GiB에서 약 8.4 GiB지만 macOS `memory_pressure -Q`의 headroom은 free pages와 다르다. admission·계속 실행에는 normal OS memory pressure, admission 이후 physical RAM의 1% 이하 swap 증가, CPU당 load 0.75 이하가 필요하다. 관측 child tree 합계는 physical RAM RSS 15%, 전체 CPU capacity 25%, 32 processes로 제한한다. CPU는 OS `ps %cpu`의 lifetime-average이며 순간 hard quota가 아니다. thread pool 환경 기본값은 1 thread다. 공유 페이지 중복 합산으로 RSS 거부가 보수적일 수 있으며 개별 프로세스 제한으로 전체 합계를 대체하지 않는다.
