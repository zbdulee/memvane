## Summary
`skills/logs/SKILL.md`: `--slo`는 window(기본 24 hours, `--hours`로 변경) 동안의 service-level lines를 출력하며 `--all`에서는 install당 한 block이다. 각 줄 이름은 `ok`, `over`, `no-data`로 끝난다. `no-data`는 줄에 필요한 row(20, `sync`는 5)보다 적다는 뜻이고 `shown`은 target 없이 보고되는 줄이다.
- `install`: `large`(route wiki folder 아래 wiki Markdown 파일 1,000개 초과), `standard`, route를 읽을 수 없으면 `unknown`. large는 별도 `hook+selector`·`lexical` target을 가지며 unknown은 standard target으로 판정하고 large verdict를 옆에 보인다.
- `hook`: selector 시간을 뺀 prompt recall duration; `hook+selector`: selector를 호출한 recall의 duration.
- `stage`: query vector 하나인 recall에 대한 각 checkout observation stage median을 자체 target과 비교. stage별 row(`pinN`, `lexicalN`, …)가 20 미만이면 표시만 하고 판정하지 않으며, 20에 도달한 stage가 없을 때만 줄이 `no-data`다. stage별 verdict(`pinStatus`, `stillCurrentStatus`, …)의 `no-data`는 줄이 `ok`여도 "not judged"로 읽는다.
- `selector`: duration과 시간 초과 answer 비율. 판정 없이 field가 있는 row에서만: `rankedOverlap`(served card가 best ranked 세 row에 든 수, `overlapRecalls` 기준; `overlapServed`·`overlapCandidates`와 함께 읽으며 자체 분모 없음), `checkpoints`, `droppedPairs`(`droppedPairRecalls`), `identityReused`(`identityReusedN` 중 checked model identity 재사용 비율). field 없는 row는 0이 아니라 제외다.
- `host <name>`: host별 duration과 semantic share.
