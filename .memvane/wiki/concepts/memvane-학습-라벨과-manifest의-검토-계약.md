## Summary
후보 관련성 라벨 `necessary`, `supporting`, `irrelevant`와 요청별 0–3개 최종 카드 선택 검토는 별도 기록이다. 모델 예측을 selection gold로 쓰지 않는다. `review-selection`은 captured input hash, reviewer ID, reference를 요구한다. `build-manifest`는 검토된 pair labels, revisions, train/calibration/validation/evaluation family splits를 고정한다. 로컬 selection queue는 온전한 reviewed selection, 모든 후보의 검토, 완전한 captured input text, v2/v3의 complete returned pool, 현재 revision hashes를 요구한다.
