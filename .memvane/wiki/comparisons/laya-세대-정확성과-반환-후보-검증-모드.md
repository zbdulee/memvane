## Summary
세대 정확성은 immutable published A-int generation의 전체 membership·bytes가 COMPLETE catalog snapshot과 같다는 보장으로, scan·stage rehash·atomic publish에 O(N + B)가 든다. live tree의 현재성은 보장하지 않는다. 반환 후보 검증은 O(returned candidates)다. indexed mode에서 `laya_host_response.py`는 `search_many`·`search_exact` 결과를 `CandidateQuery.verify_indexed_rows`로 hash 검증하며 현재 source는 읽지 않는다. 변경은 다음 게시까지 index lag로 허용된다. re-read mode의 `phase`·`verify_rows`·`search_candidates_verified`와 `LayaIndexRuntime.query_bound`는 no-follow로 현재 bytes를 읽어 변경된 행을 버린다. host hook은 이 모드를 사용하지 않는다. `max_query_files` / `max_query_bytes`가 재읽기 비용을 제한한다.
