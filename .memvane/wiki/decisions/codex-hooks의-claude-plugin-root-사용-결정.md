## Summary
`memvane/host/README.md`: `hooks-codex.json`도 `"${CLAUDE_PLUGIN_ROOT}/hooks/run-hook" <action> codex` 형태로 `${CLAUDE_PLUGIN_ROOT}`를 쓴다. 이유: 로컬 캐시의 OpenAI codex·zax·superpowers 등 모든 codex 플러그인이 이 형태를 쓰며, shell 확장과 텍스트 템플릿 치환 양쪽에서 입증된 유일한 형태다. 기각: `${PLUGIN_ROOT}` 단독은 간헐적으로만 주입돼 비면 `/hooks/run-hook`으로 해석되어 exit 127이 나고 run-hook 내부 dirname fallback으로 못 막는다. `${VAR:-fallback}` 확장과 `;`/`&&` 제어 연산자도 쓰지 않는다. run-hook 내부는 `CLAUDE_PLUGIN_ROOT→PLUGIN_ROOT→dirname` 순서로 방어한다. CLAUDE_PLUGIN_ROOT가 비면 PreToolUse `gate`도 127로 죽어 pending 편집 차단이 fail-open된다(수용 가능한 트레이드오프). Codex same-event command hooks는 동시 실행될 수 있어 posttool/index/compile은 서로 순서 의존하면 안 된다. `hooks.json`은 표준 구조 `{hooks:[{type:"command",command}]}`를 따라야 한다.
