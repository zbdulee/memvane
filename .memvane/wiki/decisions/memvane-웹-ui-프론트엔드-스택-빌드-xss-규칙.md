## Summary
`<plugin-root>/`의 `ui/`는 Preact + TypeScript(`strict: true`) + Vite를 사용한다. `ui/package.json`에 `typescript`, `preact`, `vite`를 격리하여 플러그인 캐시와 테스트 러너의 충돌을 피한다. [package.json](../package.json)은 `node --test`만 실행하고 `ui/node_modules/`는 `.gitignore` 처리한다. `ui/package-lock.json`은 다중 플랫폼 optional deps를 포함하며 `ui/tsconfig.json`·`ui/vite.config.ts`를 둔다. `ui/src/api/`에는 `types.ts`, fetch 클라이언트, Web Locks + BroadcastChannel 단일 SSE 리더를 둔다. `ui/src/components/`는 공용 레이아웃·트리·안전 마크다운·모달, `ui/src/pages/`는 Overview, Recall/Playground, Wiki Browser, Runtime/Learning을 담당한다. 플러그인은 `legalComments: 'none'`, 고정 파일명, LF 고정의 사전 빌드 `ui/dist/`만 포함하고 사용자 머신의 `npm install`·빌드·Node 실행 없이 서빙한다.
