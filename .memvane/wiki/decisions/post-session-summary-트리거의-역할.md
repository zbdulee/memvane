## Summary
`post_session_summary` 트리거는 자동 발화 경로가 없다(설계상 불가, 죽은 설정 아님). host가 compact session summary를 hook에 넘길 때를 의도했지만 그런 host가 없다: Claude Code의 SessionEnd/PreCompact/Stop은 `transcript_path`(raw JSONL)만 주고, Codex hooks·Hermes plugin hooks에는 session-end 채널이 없다. raw transcript 소스는 금지(`raw`/`session`/`source` Markdown만)이고 enqueue는 LLM을 호출하지 않아 hook-side 요약도 불가하다. 이 값은 수동 경로의 레코드 라벨로 소비되므로(`wiki_extract.py`가 payload `trigger` 기록 → `skills/wiki-compile`) `COMPILE_TRIGGERS`에서 제거하지 말 것. 세션 결론의 자동 수집은 `post_tool_source`가 담당한다.
